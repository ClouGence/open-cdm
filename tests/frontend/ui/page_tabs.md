# 页面级文字页签

## Purpose

验证 CloudDM 页面级文字页签统一复用 `AppPageTabs`，防止不同页面出现激活文字颜色、字号、字重、间距、下划线宽度和键盘交互不一致。

## Scope

- 代表页面与路由：工单 `/#/ticket`、安全规则 `/#/data-access/rules`、用户中心 `/#/settings/profile`、日志 `/#/manager/logs`、偏好设置 `/#/settings/preferences`。
- 组件：`frontend/src/components/layout/AppPageTabs.vue`。
- 交互：鼠标切换、Enter/Space 键切换、禁用项、路由或查询参数同步、刷新恢复、窄屏横向滚动。
- 不覆盖：SQL 编辑器会话标签、查询结果标签、权限树内部标签、弹窗内部标签和组件库卡片式标签；这些标签承载不同交互语义，不使用页面级页签样式。

## Preconditions

- 本地 `DmAloneLauncher` 已启动，访问地址为 `http://127.0.0.1:8222/`。
- Chrome 已登录 CloudDM，浏览器缩放为 100%。
- 当前账号至少具备工单、安全规则、用户中心、日志和偏好设置中待测页面的访问权限；缺少权限的页面按 Skip Conditions 处理。
- 页面接口可正常返回，且测试过程中不修改共享账号权限或生产数据。

## Test Data

- 工单：使用当前账号已有列表数据；列表为空也可验证页签和筛选区域。
- 安全规则：使用现有安全规则和规则模板；不创建、编辑或删除规则。
- 用户中心：使用当前登录账号，只切换“账户信息”“安全”，不修改资料或安全设置。
- 日志：使用现有操作审计和 SQL 日志，只查看列表。
- 偏好设置：只切换可见页签，不修改或保存配置。

## Suites

### PT-SMOKE-00 公共视觉规范

- 风险/目的：P0，确认代表页面使用相同的页签结构和视觉层级。
- 初始路由与状态：分别进入 Scope 中可访问的代表页面，停留在各页面默认页签。
- 测试数据：页面现有数据。
- 准备方法：等待页面 loading 结束。
- 操作步骤：依次观察每个页面的页签容器、激活项、未激活项和内容区起始位置。
- 预期结果：页签容器没有满宽底边；激活文字使用主文字色和 500 字重，未激活文字使用次级文字色和 400 字重；所有文字均为 13px；仅激活项下方展示 2px 绿色短下划线；页签水平间距、左右内边距和整体高度一致；页面中不存在同功能的下拉选择器或第二套页签皮肤。
- 恢复/清理：无。

### PT-MAIN-01 切换与页面内容同步

- 风险/目的：P0，确认迁移到公共组件后业务切换行为不变。
- 初始路由与状态：依次打开工单、安全规则、用户中心、日志和偏好设置的默认页签。
- 测试数据：页面现有数据。
- 准备方法：记录当前 URL、激活页签和代表性筛选项或内容标题。
- 操作步骤：点击每个页面的第二个可用页签，等待内容稳定，再切回第一个页签。
- 预期结果：每次只有一个页签处于激活态；内容、筛选栏和列表与激活页签一致；安全规则查询参数、日志子路由和偏好设置查询参数按页面既有规则同步；切回后恢复对应内容，不出现重复页签或旧内容覆盖。
- 恢复/清理：各页面恢复默认页签。

### PT-BOUNDARY-01 单页签与禁用项

- 风险/目的：P1，确认权限过滤或保存状态导致单页签、禁用项时布局和交互稳定。
- 初始路由与状态：使用仅具备一种日志权限的账号，或进入存在禁用页签状态的偏好设置页面。
- 测试数据：最小权限账号；偏好设置正在保存时的现有禁用逻辑。
- 准备方法：没有安全的最小权限账号或不可构造保存状态时按 Skip Conditions 处理。
- 操作步骤：检查单页签页面；使用鼠标、Enter 和 Space 尝试激活禁用页签。
- 预期结果：单页签仍保持统一高度和下划线位置；禁用项使用禁用文字色和禁用光标，鼠标与键盘均不能切换；当前内容、URL 和保存状态不改变。
- 恢复/清理：等待保存结束，恢复原账号。

### PT-EXTREME-01 响应式与长文案

- 风险/目的：P1，防止窄屏或国际化长文案导致页签重叠、换行和页面溢出。
- 初始路由与状态：选择可见页签数量最多的代表页面。
- 测试数据：中文；可安全切换语言时再验证英文或其他已配置语言。
- 准备方法：保持浏览器缩放为 100%。
- 操作步骤：依次使用 1440×900、1024×768、390×844 视口检查页签，窄屏时滑动页签容器并切换末尾页签。
- 预期结果：页签文字不换行、不重叠、不被裁切；容器宽度不足时仅页签区域横向滚动，页面本身不产生水平溢出；激活下划线始终与对应文字区域对齐；内容区不因切换产生异常跳动。
- 恢复/清理：恢复原视口和语言。

### PT-REPEAT-01 快速连续切换

- 风险/目的：P1，防止连续操作产生多个激活态或旧请求覆盖最终页面。
- 初始路由与状态：进入工单、日志或其他会在切换时请求数据的页面。
- 测试数据：正常列表数据。
- 准备方法：等待初始请求完成。
- 操作步骤：快速依次点击第二、第一、第二个页签，等待所有请求稳定。
- 预期结果：最终只有第二个页签激活；URL、筛选项和内容属于最终页签；没有重复 loading、重复页签或下划线残留。
- 恢复/清理：返回默认页签。

### PT-FAILURE-01 页面请求失败与恢复

- 风险/目的：P1，确认业务接口失败不会破坏公共页签结构。
- 初始路由与状态：进入任一会在页签切换时请求数据的代表页面。
- 测试数据：通过 Chrome 离线模式构造请求失败；无法安全控制时标记 SKIP。
- 准备方法：记录当前 URL 和激活页签。
- 操作步骤：切换离线后点击另一页签；观察错误与布局；恢复网络后重新进入或查询。
- 预期结果：失败时页签结构、激活态和可访问性属性仍完整；页面走统一错误处理；恢复网络后内容可重新加载且激活页签与 URL 一致。
- 恢复/清理：恢复网络并返回默认页签。

### PT-LIFECYCLE-01 刷新、前进后退与重新进入

- 风险/目的：P1，确认路由驱动页签和本地状态页签都能正确恢复。
- 初始路由与状态：分别进入安全规则、日志和偏好设置的第二个页签。
- 测试数据：页面现有数据。
- 准备方法：等待页面稳定。
- 操作步骤：刷新页面；使用浏览器后退和前进；离开页面后从可见导航重新进入。
- 预期结果：路由或查询参数驱动的页面刷新后仍激活正确页签；前进后退时页签与内容同步；重新进入后按页面既有默认规则展示，不出现短暂双激活或无激活状态。
- 恢复/清理：返回默认页签。

### PT-PERMISSION-01 页面权限边界

- 风险/目的：P0，防止公共组件迁移绕过页面或页签权限过滤。
- 初始路由与状态：使用完整权限、单页签权限和无页面权限账号。
- 测试数据：现有最小权限测试账号。
- 准备方法：不在共享环境临时扩大账号权限。
- 操作步骤：从可见导航进入代表页面，并尝试访问被过滤页签对应的深链接。
- 预期结果：公共组件只渲染业务层传入的可用页签；不可用页签不显示；深链接按页面原有权限逻辑重定向或拒绝；无页面权限时不展示页面内容。
- 恢复/清理：恢复原登录账号。

### PT-STATE-01 可访问性与状态一致性

- 风险/目的：P1，确认鼠标和键盘交互共享同一状态来源。
- 初始路由与状态：任一至少有两个可用页签的代表页面。
- 测试数据：页面现有数据。
- 准备方法：将焦点移动到第一个页签。
- 操作步骤：核对 `tablist`、`tab`、`aria-selected` 和 `tabindex`；使用 Enter 或 Space 激活第二个页签，再用鼠标切回。
- 预期结果：容器和页签角色正确；任一时刻仅当前页签 `aria-selected=true`；键盘与鼠标切换结果一致；焦点轮廓可见且不会改变布局尺寸。
- 恢复/清理：返回默认页签。

## Cleanup

- 将各代表页面恢复到默认页签。
- 恢复 Chrome 网络、视口、缩放、语言和测试账号。
- 本流程不创建、修改或删除业务数据。

## Skip Conditions

- 当前账号无某代表页面权限时，跳过该页面并至少验证两个其他代表页面，不用临时扩大共享账号权限。
- 没有单页签权限账号时，权限过滤场景标记 SKIP；可用静态代码检查确认过滤逻辑仍由业务页面提供。
- 页面接口没有数据时，仍验证页签、路由、筛选结构和空态；数据内容断言标记 SKIP。
- 无法安全控制离线、保存中状态或语言切换时，对应场景标记 SKIP，并保留正常网络和当前语言下的验证。
