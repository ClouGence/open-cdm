# CloudDM 离线运行时资源复测流程

## Purpose

验证 CloudDM 前端在无法访问公网的纯内网环境中，不会自动请求公网字体、样式或统计脚本，并且本地图标字体与 SQL 编辑器仍可正常显示。

## Scope

- 前端入口：登录后的 CloudDM 主页面、数据源图标及 SQL 编辑器。
- 资源：随 Web 包发布的 CSS、JavaScript、Monaco Worker、`i-clouddm` 图标字体及 Luckysheet 静态资源；不发布 iconfont 示例页面。
- 网络：页面自动发起的静态资源和统计请求。
- 不覆盖：用户主动点击帮助文档、版本下载、支持网站等外部链接；第三方数据源、Webhook、代码仓库等用户配置的业务连接。

## Preconditions

- 本地 `DmAloneLauncher` 可访问，或已部署待验证的内网安装包。
- 使用具有数据查询页面权限的普通账号登录 Chrome。
- Chrome 测试标签页位于 `codex` 标签页组。
- 测试前清空该标签页的网络记录并禁用缓存，避免浏览器缓存掩盖缺失资源。

## Test Data

- 一个可进入数据查询页面的数据源，优先包含通过 `CcIconfont` 展示的数据源类型。
- 一段只读 SQL，例如 `SELECT 1;`，不执行写操作。
- 无需创建或删除业务数据。

## Suites

### OFFLINE-ASSET-SMOKE-01 页面资源全部来自当前站点

- 风险或目的：防止字体、样式、脚本仍依赖公网 CDN。
- 优先级：P0。
- 初始路由与状态：登录后主页面，网络面板已清空并禁用缓存。
- 操作步骤：刷新页面；等待加载完成；进入数据查询页并打开一个 SQL 编辑器；检查本次导航产生的全部请求域名。
- 预期结果：自动请求仅访问当前 CloudDM 地址及其同源 API/WebSocket；不存在 `at.alicdn.com`、`hm.baidu.com` 或其他公网静态资源/统计请求；页面无字体、CSS、Worker 加载失败。
- 恢复/清理：无。

### OFFLINE-ASSET-MAIN-01 本地图标字体可见

- 风险或目的：防止字体改为本地路径后出现空白或方框图标。
- 优先级：P0。
- 初始路由与状态：包含数据源图标或顶部操作图标的页面。
- 操作步骤：刷新页面；观察数据源类型图标和顶部操作图标；检查 `i-clouddm` 字体请求。
- 预期结果：图标轮廓清晰且不是空白、方框或普通字符；字体请求为当前站点生成的本地字体资源，状态成功。
- 恢复/清理：无。

### OFFLINE-ASSET-MAIN-02 SQL 编辑器无需外部字体

- 风险或目的：确认 SQL 字体回退链在隔离环境可用。
- 优先级：P1。
- 初始路由与状态：SQL 编辑器或工单 SQL 内容已打开。
- 操作步骤：查看多行 SQL、关键字高亮、行号和横向滚动；检查网络请求。
- 预期结果：SQL、行号和高亮完整可读；字体使用本机可用的 Menlo、Monaco、Courier New 或系统等宽字体；不产生字体公网请求。
- 恢复/清理：无。

### OFFLINE-ASSET-BOUNDARY-01 空缓存首次访问

- 风险或目的：排除本机曾访问公网后缓存命中的假通过。
- 优先级：P0。
- 初始路由与状态：禁用缓存并清除当前站点缓存后的登录页。
- 操作步骤：首次进入主页面和数据查询页；重新检查资源域名与失败请求。
- 预期结果：所有必要资源均从当前站点成功加载；没有依赖已有浏览器公网缓存。
- 恢复/清理：恢复缓存设置。

### OFFLINE-ASSET-EXTREME-01 公网请求被阻断

- 风险或目的：模拟严格防火墙仅允许 CloudDM 地址的部署环境。
- 优先级：P0。
- 初始路由与状态：仅允许当前 CloudDM 地址和本地回环地址，阻断其他域名。
- 操作步骤：刷新主页面；进入数据查询页；打开 SQL 编辑器；切换包含不同数据源图标的页面。
- 预期结果：核心页面、图标和 SQL 编辑器正常显示；无持续重试、长时间 loading 或公网资源失败；控制台无资源加载错误。
- 恢复/清理：撤销临时网络阻断规则。

### OFFLINE-ASSET-REPEAT-01 重复刷新与多标签页

- 风险或目的：防止资源路径仅首次访问有效或并发加载失败。
- 优先级：P1。
- 初始路由与状态：主页面已加载。
- 操作步骤：连续刷新两次；在第二个 `codex` 标签页打开数据查询页；观察两页资源请求和图标显示。
- 预期结果：两页均只使用同源资源，字体加载成功，不出现公网重试或随机缺图标。
- 恢复/清理：关闭本场景新开的测试标签页。

### OFFLINE-ASSET-FAILURE-01 本地字体加载失败后恢复

- 风险或目的：确认本地字体资源异常不会导致页面整体不可用，并能在资源恢复后正常加载。
- 优先级：P1。
- 初始路由与状态：通过可撤销的请求阻断，仅阻断当前站点生成的 `i-clouddm` 字体文件。
- 操作步骤：刷新页面并确认字体请求失败；观察页面其余区域；撤销阻断后再次刷新。
- 预期结果：阻断期间页面主体、菜单和文字仍可操作，仅字体图标受到影响；不存在公网地址兜底或持续公网重试；恢复后本地图标重新正常显示。
- 恢复/清理：撤销字体请求阻断并刷新页面。

### OFFLINE-ASSET-LIFECYCLE-01 路由切换与重新进入

- 风险或目的：防止懒加载页面在首次进入时才触发公网资源。
- 优先级：P1。
- 初始路由与状态：登录后主页面。
- 操作步骤：依次进入数据查询、实例、CI/CD、工单和设置页面；返回数据查询页；检查新增请求。
- 预期结果：所有懒加载资源均来自当前站点；路由切换后图标和编辑器仍正常，无公网字体或统计请求。
- 恢复/清理：返回初始页面。

### OFFLINE-ASSET-PERMISSION-01 不同权限入口

- 风险或目的：确认权限差异不会加载另一套公网资源。
- 优先级：P2。
- 初始路由与状态：分别使用完整权限账号和只读账号。
- 操作步骤：登录后进入各自可见的首个页面；刷新并检查资源域名。
- 预期结果：不同权限页面均只自动请求同源资源；无权限页面不影响已有本地字体加载。
- 恢复/清理：退出测试账号。

### OFFLINE-ASSET-STATE-01 资源恢复后的状态一致性

- 风险或目的：防止一次字体加载失败后页面长期保留错误缓存或错误状态。
- 优先级：P1。
- 初始路由与状态：已完成本地字体加载失败场景并恢复请求。
- 操作步骤：刷新当前页面；切换到另一个包含 `CcIconfont` 的路由后返回；再次检查请求地址和图标。
- 预期结果：字体从当前站点成功加载，所有图标恢复；路由切换前后不存在公网请求、重复错误提示或异常 loading 状态。
- 恢复/清理：无。

## Cleanup

- 恢复 Chrome 缓存和临时网络阻断设置。
- 关闭本流程创建的额外测试标签页。
- 本流程不创建业务数据，无数据清理操作。

## Skip Conditions

- 无法控制防火墙或请求阻断时，可执行空缓存首次访问，并以构建产物中不存在公网字体、样式和统计地址作为替代验证；必须报告严格阻断场景未覆盖。
- 没有可用数据源时，可在登录后页面验证图标字体和同源请求；SQL 编辑器场景标记跳过。
- 无第二种权限账号时，权限场景标记跳过，不影响 P0 离线资源验收。
