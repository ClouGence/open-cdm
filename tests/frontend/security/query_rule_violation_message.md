# 查询安全规则违规提示表头

## Purpose

验证查询安全规则中承载规则命中提示的 `ruleDesc` 字段统一显示为“违规提示”，规则详情入口通过弹窗展示且不离开 SQL 工作台，同时确保脱敏规则和规则编辑表单继续使用“规则描述”，防止不同语义的字段标题被全局误改。

## Scope

- 页面与路由：安全规则库页面、安全规范详情页和 SQL 工作台规则校验失败弹窗。
- 关联源码：`frontend/src/views/security/rule/index.vue`、`frontend/src/views/security/spec/specDetail.vue`、
  `frontend/src/views/sql/components/SqlViewer.vue`、`frontend/src/locales/zh.json`、`frontend/src/locales/en.json`。
- 覆盖：查询规则表头、SQL 工作台规则详情弹窗、脱敏规则表头隔离、刷新与中英文切换。
- 不覆盖：规则检测算法、规则参数计算、告警等级和 SQL 是否允许执行。

## Preconditions

- 本地 `DmAloneLauncher` 已通过 IDEA 启动，访问地址为 `http://127.0.0.1:8222/`。
- Chrome 已登录具备安全规则、安全规范和 SQL 查询权限的测试账号。
- 环境中至少存在一条内置查询规则和一条脱敏规则；验证 SQL 弹窗时需启用一条可由只读 SQL 稳定命中的查询规则。

## Test Data

| 编号 | 数据说明 | 构造方式 | 清理方式 |
|---|---|---|---|
| QRV01 | 内置查询规则 | 使用现有“查询语句中的空条件”等内置规则 | 无需清理 |
| QRV02 | 内置脱敏规则 | 使用现有任意脱敏规则 | 无需清理 |
| QRV03 | 只读违规 SQL | 根据当前启用规范选择可稳定命中规则的 `SELECT`，不得包含数据写入 | 关闭结果页签 |

## Suites

### QRV-SMOKE-01 查询规则库表头

- 风险/目的：P1，确认查询规则提示不再被误称为规则描述。
- 初始路由与状态：进入安全规则库页面，切换到查询规则分类，规则列表加载完成。
- 测试数据：QRV01。
- Chrome 操作：观察规则名称右侧的列标题及其内容；刷新页面后再次观察。
- 预期结果：列标题为“违规提示”；单元格仍展示原有规则命中提示，规则名称、数据源范围和操作列不变。
- 恢复/清理：无需清理。

### QRV-MAIN-01 安全规范详情表头

- 风险/目的：P1，确认规范内引用的查询规则使用相同语义标题。
- 初始路由与状态：打开包含查询规则的安全规范详情，查询规则分类处于选中状态。
- 测试数据：QRV01。
- Chrome 操作：观察查询规则列表表头，切换分页或刷新页面。
- 预期结果：规则名称右侧显示“违规提示”；分页和刷新后标题保持一致，规则数据不发生变化。
- 恢复/清理：无需清理。

### QRV-MAIN-02 SQL 规则校验弹窗

- 风险/目的：P1，确认真实命中规则时弹窗使用“违规提示”。
- 初始路由与状态：进入 SQL 工作台，已选择启用查询安全规范的只读数据源。
- 测试数据：QRV03。
- Chrome 操作：执行只读违规 SQL，在规则校验失败提示中打开规则详情列表。
- 预期结果：点击“查看详情”后 URL 仍为 `/#/sql`，页面中央打开“规则校验失败”弹窗；规则列表对应列标题为“违规提示”，内容为具体违规原因，等级、规则名称和行号列保持不变；关闭弹窗后仍停留在 SQL 工作台并保留执行信息。
- 恢复/清理：关闭弹窗及新增结果页签。

### QRV-BOUNDARY-01 查询与脱敏语义隔离

- 风险/目的：P0，防止全局替换导致脱敏规则和规则编辑表单误显示“违规提示”。
- 初始路由与状态：安全规则库和安全规范详情均可切换查询规则、脱敏规则分类。
- 测试数据：QRV01、QRV02。
- Chrome 操作：在查询规则和脱敏规则之间往返切换；打开一条可编辑规则。
- 预期结果：查询规则列表显示“违规提示”；脱敏规则列表和规则编辑表单仍显示“规则描述”；切换过程无标题串位。
- 恢复/清理：关闭规则编辑页面，不保存修改。

### QRV-EXTREME-01 常见视口与国际化

- 风险/目的：P2，确认新标题在常见桌面宽度及中英文下完整可辨认。
- 初始路由与状态：查询规则列表已加载。
- 测试数据：QRV01。
- Chrome 操作：分别在 1440×900 和 1024×768 视口观察表头；切换中文和英文后重新进入页面。
- 预期结果：中文显示“违规提示”，英文显示“Violation message”；表头不与相邻列重叠，窄屏下既有表格横向滚动行为不变。
- 恢复/清理：恢复原语言和视口。

### QRV-LIFECYCLE-01 刷新与重新进入

- 风险/目的：P2，确认动态列定义在组件重新创建后仍使用正确文案。
- 初始路由与状态：查询规则列表可见。
- 测试数据：QRV01。
- Chrome 操作：刷新页面，离开后重新进入规则库和安全规范详情，并切换查询/脱敏分类。
- 预期结果：查询规则始终显示“违规提示”，脱敏规则始终显示“规则描述”；控制台无新增错误。
- 恢复/清理：无需清理。

### QRV-PERMISSION-01 页面权限

- 风险/目的：P2，确认文案调整不改变既有权限边界。
- 初始路由与状态：分别使用具有安全规则权限和不具有该权限的账号。
- 测试数据：无需额外数据。
- Chrome 操作：使用有权限账号进入查询规则列表；使用无权限账号尝试通过菜单和直接路由进入。
- 预期结果：有权限账号正常看到“违规提示”；无权限账号仍按既有逻辑隐藏入口或显示无权限页面，不因文案调整获得页面内容。
- 恢复/清理：恢复原测试账号。

### QRV-REPEAT-01 重复切换

- 风险/目的：P3，确认快速切换分类不会复用错误的列标题。
- 初始路由与状态：规则库页面已加载查询规则和脱敏规则。
- 测试数据：QRV01、QRV02。
- Chrome 操作：连续多次切换查询规则和脱敏规则分类。
- 预期结果：每次切换后的标题都与当前规则类型匹配，不出现闪烁后的错误终态。
- 恢复/清理：停留在查询规则分类。

## Skip Conditions

- 无安全规则页面权限时，规则库和规范详情场景标记为 `SKIP`，保留源码映射、lint、国际化检查和构建结果。
- 没有启用且可安全命中的查询规范时，SQL 弹窗场景标记为 `SKIP`，不得为了验证文案修改生产或共享环境规则配置。
- 无可切换账号时，权限场景标记为 `SKIP`，不得通过修改前端状态绕过权限。
