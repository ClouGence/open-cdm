# 安全规则只读权限与冲突浮层

## Purpose

验证规则与环境只读权限，并确认规则引用冲突中的环境说明沿用白色自适应浮层。

## Scope

- `/#/data-access/rules`、安全规则详情中的查询和脱敏规则、规则模板应用弹窗。
- `/#/env` 的安全规则配置、审批模板配置和控制台只读开关。
- 查询、启用状态变更、环境引用检查与模板应用预检查；不覆盖强制应用规则。

## Preconditions

- 使用 [@Browser](plugin://browser@openai-bundled) 内置浏览器，管理员与只读账号分别使用独立登录会话。
- 只读角色仅具备对应 READ 权限，不具备 `DM_SECRULES_MANAGE`、`RDP_ENV_MANAGE`。
- 只允许修改带唯一测试前缀的空环境与规则，不绑定实例，不改共享环境和规则。

## Test Data

- 创建 `codex_ui_<唯一标识>` 空环境与同名规则，填写长环境描述，通过正常环境配置关联两者。
- 只读账号由管理员通过正常账号页面创建，不分配数据库访问权限；测试完成后停用。

## Suites

### SRC-PERMISSION-01 只读控件

- 风险/目的：P0，查看权限不能呈现写入入口。
- 初始状态：只读账号登录，访问规则列表与测试规则详情。
- @Browser 操作：检查列表新建、名称和描述编辑、删除及启用开关；分别进入查询和脱敏规则，检查设置按钮与启用开关。进入环境页检查配置和禁用按钮、控制台只读开关。整页刷新并尝试 `?type=create` 深链接。
- 预期：只读规则列表没有新建、编辑和删除入口，启用开关禁用；规则详情保留查看和范围入口，隐藏设置、禁用开关；环境页不提供任何配置或禁用按钮，控制台只读开关禁用。创建深链接不打开写入表单。管理员原有操作仍可用。
- 清理：恢复管理员会话，不修改现有对象。

### SRC-STATE-01 引用冲突与取消

- 风险/目的：P0，冲突说明完整显示且取消不改变状态。
- 初始状态：管理员，测试环境引用测试规则；只在该空环境对应规则操作。
- @Browser 操作：尝试关闭规则集，检查引用环境及描述浮层后取消；在明细启用一条测试规则，再尝试关闭并取消；规则模板应用时只选择该测试规则集，关闭多选下拉后核对唯一选项，触发预检查并取消两层弹窗。
- 预期：三个冲突弹窗均只显示隔离测试环境；不点击强制关闭或强制应用；取消后原启用状态保持。长说明白底、完整换行，无复制按钮和内部滚动条；1440×900、1024×768、390×844 下浮层不出视口。
- 清理：先删除自己创建的空环境，再删除无引用的测试规则，停用测试账号；不改其他记录。

## Cleanup

恢复视口和原会话，关闭临时弹窗及标签页；没有共享环境变更、强制规则操作或数据库写入。

## Skip Conditions

没有允许写入的隔离空环境时不构造引用冲突，明确报告覆盖缺口。没有可用只读账号时不能用管理员页面代替权限验证。
