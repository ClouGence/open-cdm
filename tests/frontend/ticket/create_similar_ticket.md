# 创建相似 SQL 工单

## Purpose

从已有 SQL 工单预填新工单，同时保持原记录和审批执行流程独立；仅支持在线 SQL 工单。

## Scope

- 工单详情及 `/ticket_create?sourceTicketId=...` 创建页。
- 现有工单基础信息、SQL 详情、SQL 内容预览和校验提交接口。
- 不包含 SQL 附件复制、记住上次工单类型/目标库、自动筛除已执行 SQL、关闭原工单或复制审批结果。

## Preconditions

- 本地后端和 Worker 就绪；使用当前源码开发前端，或确认已部署最新 Web 资源。
- @Browser 已登录具有工单读取和提交权限的测试账号。
- 本地环境使用 Internal SQL 工单审批和隔离数据库，不使用第三方审批模板。
- 元数据库与 JDBC 时区一致，附件基础上传/预览可用；不得通过取消过期校验绕过环境问题。

## Test Data

- 名称使用 `codex_similar_ticket_<唯一后缀>`；通过名称和本次创建的工单号定位，不依赖固定 ID。
- S1：标题、描述、目标实例、数据库/schema 和在线只读 SQL 完整的测试工单。
- S2：带 UTF-8 `.sql` 附件的测试工单，内容为 `SELECT 1 AS similar_ticket_check;`，记录文件名和大小。
- S3：权限工单及不存在的来源工单。
- S4（可选）：原实例或库已不可用的隔离工单，不删除共享数据源来构造。
- 不提交或执行原业务工单中的写入 SQL，不审批测试工单。

## Suites

### SIM-SMOKE-01 详情入口与工单类型

- 优先级/目的：P0，防止非 SQL 工单出现复制入口。
- 初始状态：列表已加载。
- 操作：定位 S1，确认列表操作列只有“查看”；打开详情，检查“创建相似工单”按钮；检查 S3 权限工单详情。
- 预期：SQL 工单仅在详情显示入口，点击进入携带来源 ID 的创建页，不立即创建工单；权限工单不显示入口。
- 清理：返回列表，不修改原记录。

### SIM-MAIN-01 在线 SQL 预填与重新提交

- 优先级/目的：P0，防止误改原工单或复用旧审批结果。
- 初始状态：S1 详情页。
- 操作：创建相似工单，检查标题、描述、实例、库/schema 和 SQL；修改标题及只读 SQL，点击校验并等待新详情。
- 预期：字段正确预填且可编辑，目标来自当前可选列表；预填成功后不显示额外提示横幅。新工单 ID 与原工单不同，重新分析和审批；原 SQL、标题、描述及状态保持不变，不继承审批意见或执行任务。
- 清理：保留本次测试工单供核对，可通过正常关闭流程关闭，不审批或执行。

### SIM-MAIN-02 附件工单不支持复制

- 优先级/目的：P0，保证复制范围仅包含在线 SQL。
- 初始状态：S2 详情页。
- 操作：检查详情操作；直接携带 S2 来源 ID 打开创建页。
- 预期：附件工单不显示“创建相似工单”；直接打开也显示读取失败，不能提交，不生成附件副本。正常新建工单的附件上传保持原有行为。
- 清理：返回列表，不修改原附件。

### SIM-FAILURE-01 无效来源、权限和目标不可用

- 优先级/目的：P0，避免来源读取失败后误提交空表单。
- 初始状态：从列表进入新的创建页。
- 操作：使用不存在的来源 ID 打开复制页并重试；有权限矩阵账号时检查仅有读取/仅有提交权限和不可读来源；有 S4 时复制其内容。
- 预期：无效来源显示失败与重试，表单和提交不可操作，不创建新工单。来源读取复用现有接口的读取权限、账号归属及自定义审批可读性检查；新工单提交复用现有提交权限检查；非 SQL 和附件来源不预填。不可用实例留空并提示重选；不可用库/schema 不填成无效选项，提交仍走现有校验。
- 清理：返回列表，恢复账号，不撤销共享权限。

### SIM-LIFECYCLE-01 刷新、重复提交与布局

- 优先级/目的：P1，防止依赖一次性浏览器存储、重复提交或控件遮挡。
- 初始状态：预填完成且未提交。
- 操作：刷新，从详情重新进入；在同一创建页切换来源及移除来源参数返回普通新建；提交中重复点击校验；在 1440×900、1024×768、390×844 检查并滚动到底部，检查中英文。
- 预期：刷新从 URL 中来源重新预填，不保留旧校验结果。来源切换后只显示新来源内容；普通新增页保持新标题、空目标和空 SQL，不残留旧附件。加载/读取失败时不能编辑提交，提交中禁止重复请求。窄屏目标、SQL、表单和提交按钮可达，无整页水平溢出。
- 清理：恢复视口和语言，不改其他查询页签正文。

### SIM-LARGE-01 大 SQL 与分页边界

- 优先级/目的：P0，验证 1000 行分页读取后的内容完整性。
- 初始状态：本地隔离库，具有在线 SQL 工单读取和提交权限。
- 测试数据：分别创建 1000、1001、10000 行 SQL，每行使用 `SELECT <行号> AS copy_line_<五位行号>;`；另建 10001 行，包含第 1000 行空行、第 1001 行中文注释和第 2000 行中文字符串。
- 操作：通过页面提交来源工单，从详情点击“创建相似工单”；在编辑器全选、复制，取回文本，与生成的原文逐字和 SHA-256 比对。检查分页边界、首尾行和行数；刷新 10000 行复制页后再次比对。不得仅检查屏幕当前可见的 SQL 片段。
- 预期：全文一致，无遗漏、重复或拼接换行错误；10000 行普通样本为 318893 UTF-8 字节。中文及空行保留，目标库、标题和描述正确；刷新后内容一致。创建与复制均不执行 SQL，测试工单保持未执行状态。
- 清理：保留本次唯一名称的来源工单供核对，不审批或执行；未提交的复制表单不产生新工单。

### SIM-PERF-01 十万行预填与页面响应

- 优先级/目的：P1，区分内容正确、加载等待和主线程失去响应。
- 测试数据：100000 行在线只读 SQL，每行 `SELECT <行号> AS copy_line_<六位行号>;`，无末尾换行，UTF-8 为 3388894 字节。
- 操作：从页面输入并提交来源工单；在分析中或待审批时从详情复制。分别记录首次加载、刷新和再次进入直至表单解除 inert 的耗时；加载期间打开/关闭顶栏菜单。完成后全选复制比对原文，跳至末行，输入短注释后撤销，记录可见结果的响应耗时；对照 10000 行样本。
- 预期：全文、行数、首尾内容一致，无浏览器错误；失败时不预填部分内容；加载期间切换来源或离开页面后，旧结果不覆盖新表单且不再启动后续批次；菜单可响应，末行可达，短文本编辑和撤销成功。加载耗时必须单独报告，不能以全文一致推断没有卡顿；端到端浏览器操作耗时包含自动化开销，不等同于 FPS 或并发压测。
- 性能关注：当前预览接口每页最多 1000 行，十万行仍需读取 100 页；前端先读取第一页获取总行数，再以最多 4 页一批并发读取并按页序拼接。后端每页重新扫描全文的成本仍然存在。即使编辑器可正常操作，也必须如实报告这条读取路径的明显等待。
- 清理：不审批或执行来源工单；撤销响应测试产生的临时注释，保留原文。

## Cleanup

- 仅识别本次唯一前缀工单，保留原工单和附件；退出未提交表单。
- 不手工删除其他用户的 EDITING 附件。
- 恢复临时账号、语言、视口和测试运行配置；服务需留给用户核对时明确说明。

## Skip Conditions

- 未登录时暂停依赖登录的操作，请用户在 @Browser 登录。
- 没有权限矩阵账号或不可用目标 fixture 时记录未覆盖项，以权限检查和目标恢复代码检查补充，不声称完成真实账号切换。
- 基础附件上传/预览因时钟、存储或数据库失败时先排除环境问题，不能跳过过期或归属检查。
