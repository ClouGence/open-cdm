# SQL 工作台空态与权限申请

## Purpose

验证查询工作台按账号权限提供可执行的入口，防止无数据源权限的子账号只看到禁用的新增按钮，或需要从深层菜单寻找权限申请。

## Scope

- 页面：`/#/sql` 空态、现有权限申请页 `/#/system/permission?type=apply`、数据源管理页。
- 状态：工作台恢复及数据源加载完成、没有可用数据源、已有可用数据源但未打开查询页签、有新增权限、无新增权限、无法申请的账号。
- 接口：`browse/listLevels`；权限页沿用已有资源和授权查询接口。本流程不提交权限工单、不修改审批流程或权限模型。
- 未配置外部审批时，后端默认使用内置审批；没有独立的权限申请开关，不构造虚假的关闭配置。

## Preconditions

- 前端 lint、国际化检查、现有单测和 `cd package && ./all_build.sh web` 已成功。
- 后端由 IDEA 启动且健康检查通过，前端开发服务已编译完成。在 [@Browser](plugin://browser@openai-bundled) 登录测试账号。
- 使用独立测试账号及登录地址，避免关闭原账号的 SQL 草稿或更改原有权限。记录语言、主题、视口和侧栏状态。
- 8222 打包入口验收前执行 `cd backend && ./gradlew :cgdm-web:jar`，通过 pika-idea-control 重启并确认服务加载新资源。

## Suites

### ES-PERMISSION-01 无权限子账号直接申请

- P0；初始路由 `/#/sql`，使用 ES01，等待工作台与数据源加载结束。
- 预期：显示“申请数据源权限”，没有“新建数据源”按钮；说明当前账号尚未获得数据源权限，并提供无法申请时联系管理员的指引。
- 操作：点击申请入口，核对 URL；选择现有测试资源检查表单，再返回查询页，整页刷新后再次进入申请。
- 预期：直接到 `/#/system/permission?type=apply`，处于申请编辑模式，有“提交申请”入口，不需要额外切换申请模式；刷新和重新进入后入口保持一致。不得点击最终提交。
- 清理：取消选择并返回查询页，保持账号权限不变。

### ES-PERMISSION-02 有新增权限的账号

- P0；初始路由 `/#/sql`，使用 ES02，无查询页签。
- 操作：等待加载完成，点击“新建数据源”，然后返回查询页。
- 预期：新增按钮可用，打开现有数据源管理页；不显示权限申请按钮。不得创建或更改数据源。
- 清理：返回查询页，保留原有数据源和草稿。

### ES-STATE-01 已有数据源但未打开查询

- P1；初始路由 `/#/sql`，使用 ES03。
- 操作：加载数据源树，观察空态；从左侧打开测试实例的查询页签，再关闭本次未执行的新页签。
- 预期：空态使用从左侧开始查询的指引，不误称没有数据源权限，不显示新增或申请按钮；查询页签正常打开，关闭后回到同一空态。
- 清理：仅关闭本次新页签，不执行 SQL。

### ES-STATE-02 无法申请时的指引

- P1；使用 ES04，数据源加载已完成、无可用数据源及新增权限。
- 预期：显示联系管理员获取数据源权限的说明，不显示无法使用的新增或权限申请按钮。账号类型判断遵循现有权限页及路由的子账号限制。
- 清理：恢复原账号；不能通过修改 Vue 状态或伪造接口数据代替真实账号验收。

### ES-LAYOUT-01 中英文、主题与视口

- P1；使用 ES01 和 ES02，依次在 1440×900、1024×768、390×844 检查空态，通过产品入口切换中英文和明暗主题。
- 预期：新增、申请及管理员指引均有中英文文案；申请按钮的图标与现有权限入口一致；两种按钮沿用工作台原有主题绿色、44px 高度和 6px 圆角；按钮与文字有足够对比度，长英文不溢出或遮挡，窄屏折叠侧栏后入口可达；加载恢复期间不闪现错误空态。
- 清理：恢复原语言、主题和视口。

## Cleanup

1. 不提交权限申请，不给测试账号增加业务资源权限；取消所有本次表单选择。
2. 关闭本次临时页签，停用本次创建的测试账号；需要后续 review 时可保留其最小角色。移除账号或角色前确认不被其他流程引用，不记录测试密码。
3. 恢复原账号、语言、主题、视口及服务状态，保留原 SQL 草稿。

## Skip Conditions

- 缺少可登录的 ES01、ES02 或 ES03 时，相应浏览器流程标记 BLOCKED；组件级验证不能替代真实账号导航。
- 无法构造 ES04 时，记录未做实际账号验收，组件级验证只补充判断和文案覆盖。
- Browser 不支持视口或主题控制时，明确记录未覆盖项；不能以静态样式检查替代浏览器布局验证。
