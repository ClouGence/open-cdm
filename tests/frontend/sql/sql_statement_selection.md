# SQL 语句选择与错误隔离

## Purpose

验证 SQL 工作台中某一条语句存在语法错误时，错误诊断不会阻断其他语句的光标选择和执行；后端语句切分不可用或结果过期时，编辑器仍能按分号、引号和注释边界选择当前语句。

## Scope

- 页面与路由：`/#/sql`。
- 入口：SQL 工作台查询页签、工具栏“执行”。
- 关联状态：语法诊断、光标移动、手动文本选择、语句切分请求、快速编辑、断线与恢复。
- 关联源码：`frontend/src/components/editor/index.vue`。
- 不覆盖：数据库方言对每种 SQL 语法的完整解析正确性、DML/DDL 业务结果、执行计划正确性。

## Preconditions

- 本地 `DmAloneLauncher` 已通过 IDEA 启动，访问地址为 `http://127.0.0.1:8222/`。
- Chrome 已登录具备 SQL 查询权限的测试账号。
- 已连接一个允许执行只读 `SELECT` 的隔离测试数据源。
- 测试期间不执行 DDL、DML 或生产数据查询。

|---|---|---|---|

| D02 | 分号边界 | `SELECT 'a;b';`、`SELECT \"c;d\";`、包含分号的行注释与块注释 | 清空未保存查询页签 |

## Suites

### SSS-SMOKE-01 多条有效语句独立选择

- 风险/目的：P0，确认正常语句切分与执行没有回归。
- 初始路由与状态：进入 `/#/sql` 并打开查询页签。
- 测试数据：D01 中去掉错误语句后的两条有效 SQL。
- Chrome 操作：分别将光标放入每条 SQL 的关键字、参数和结尾分号处，观察当前语句提示框；每次点击“执行”。
- 预期结果：提示框只包围光标所在语句；执行按钮保持可用；每次只执行当前语句，结果与执行信息不包含另一条 SQL。
- 恢复/清理：清空执行结果和查询页签。

### SSS-MAIN-01 语法错误不阻断其他语句

- 风险/目的：P0，复现并验证 DataGrip 风格的错误隔离行为。
- 初始路由与状态：查询页签已连接测试数据源。
- 测试数据：依次输入 `SELECT 1;`、`SELECT * FROM ;`、`SELECT version();`，语句间保留空行。
- Chrome 操作：等待错误诊断出现；将光标移入最后一条有效 SQL，再点击“执行”；随后将光标移入错误 SQL，但不要求执行。
- 预期结果：错误 SQL 继续显示红色诊断；光标位于最后一条有效 SQL 时，提示框只包围该语句，执行按钮可用且只执行 `SELECT version();`；光标位于错误 SQL 时，该语句仍可被提示框选中，错误标记不消失。
- 恢复/清理：清空执行结果和查询页签。

### SSS-BOUNDARY-01 空白、分号、引号与注释边界

- 风险/目的：P1，防止本地切分把字符串或注释中的分号误认为语句结束。
- 初始路由与状态：查询页签已打开。
- 测试数据：D02。
- Chrome 操作：依次把光标放在字符串内的分号、SQL 结尾分号、两条语句之间的纯空白行、行注释和块注释内。
- 预期结果：字符串和注释中的分号不切断语句；结尾分号属于前一条语句；纯空白行不显示当前语句提示框，点击执行只提示没有可执行 SQL 且不发送查询；注释与其后的 SQL 保持在同一分号片段中。
- 恢复/清理：清空查询页签。

### SSS-EXTREME-01 大量语句与常见视口

- 风险/目的：P1，确认本地回退在长文档和窄视口下仍能及时定位当前语句。
- 初始路由与状态：查询页签已打开。
- 测试数据：复制 200 条只读 `SELECT`，在中间插入一条错误 SQL。
- Chrome 操作：在 1440×900、1024×768、390×844 下分别移动到错误语句前后并选择有效语句，连续滚动到文档首尾。
- 预期结果：选择提示跟随光标，无明显卡顿或错位；错误前后的有效语句均可独立选择；页面无非预期横向溢出。
- 恢复/清理：恢复原窗口尺寸并清空页签。

### SSS-STYLE-01 SQL 编辑器双向滚动条

- 风险/目的：P1，确认 Monaco 横向和纵向滚动条与产品通用滚动条保持一致，不出现默认粗直角滑块。
- 初始路由与状态：查询页签已打开。
- 测试数据：D05。
- Chrome 操作：在 1440×900、1024×768、390×844 下输入超宽单行 SQL 和足量多行 SQL，分别拖动横向、纵向滑块到首尾，并悬停观察滑块。
- 预期结果：纵向轨道宽 5px、横向轨道高 8px；轨道与滑块均为圆角，浅色主题使用产品通用的半透明灰色层级，暗色主题使用主题变量；两个方向均可连续滚动且不遮挡 SQL、行号或结果区。
- 恢复/清理：恢复原窗口尺寸并清空页签。

### SSS-STYLE-02 执行信息终端层级

- 风险/目的：P1，确认执行信息在成功、失败和长 SQL 场景下仍能快速区分命令与结果，并与全局 SQL 字体统一。
- 初始路由与状态：查询页签已打开，底部“执行信息”页签可见。
- 测试数据：D06。
- Chrome 操作：依次执行成功和失败 SQL；在 1440×900、1024×768、390×844 下查看执行信息，依次点击右侧滚动到顶部、自动滚动到底部和清空按钮。
- 预期结果：数据库提示符与 SQL 命令同行，SQL 关键字为蓝色；时间和普通结果使用中性色，错误结果使用深红色；全部内容使用项目统一 SQL 等宽字体、14px 字号和 21px 行高；长 SQL 可换行且不遮挡右侧操作栏，消息顺序与原执行顺序一致；右侧操作栏宽 44px，三个 28px 方形点击区居中排列且纵向间隔 8px，滚动时操作组保持在栏内可见，三个操作均可正常执行。
- 恢复/清理：清空执行信息，恢复原窗口尺寸并清空页签。

### SSS-REPEAT-01 快速编辑与过期响应

- 风险/目的：P0，防止较晚返回的语句切分结果覆盖新文档状态。
- 初始路由与状态：查询页签已输入 D01。
- 测试数据：D03。
- Chrome 操作：在一秒内连续删除、恢复错误语句并快速移动光标到最后一条有效 SQL，重复十次。
- 预期结果：提示框始终对应当前模型和当前光标；旧切分响应不会令提示框跳回已删除语句；执行目标与提示框一致。
- 恢复/清理：停止编辑后等待请求完成并清空页签。

### SSS-FAILURE-01 语句切分服务失败与恢复

- 风险/目的：P0，确认 WebSocket 语句切分失败时仍可本地选择语句。
- 初始路由与状态：查询页签已成功连接数据源。
- 测试数据：D01。
- Chrome 操作：仅在隔离环境中临时断开网络或阻断语句切分请求；将光标放入错误语句后的有效 SQL；恢复网络后再次移动光标。
- 预期结果：断线期间有效 SQL 仍可选择，执行按钮状态由当前本地语句决定；恢复后后端精确切分重新生效，当前语句没有跳错或重复装饰。
- 恢复/清理：恢复网络并确认 WebSocket 重连。

### SSS-LIFECYCLE-01 页签切换、刷新与初始语法诊断

- 风险/目的：P1，确认编辑器重建不会遗留旧语句状态。
- 初始路由与状态：两个查询页签分别含有效和错误 SQL。
- 测试数据：D01。
- Chrome 操作：快速切换页签、关闭并重建页签、刷新页面后重新进入包含错误 SQL 的查询；刷新后不编辑内容，等待语法校验完成。
- 预期结果：提示框只存在于当前页签当前语句；关闭或刷新后旧装饰和旧执行目标不会残留；首次加载或刷新恢复的错误 SQL 无需再次编辑就显示红色语法诊断。
- 恢复/清理：关闭测试页签。

### SSS-PERMISSION-01 最小查询权限

- 风险/目的：P1，确认语句选择不依赖管理权限。
- 初始路由与状态：使用仅具备目标数据源查询权限的账号进入 SQL 工作台。
- 测试数据：D01。
- Chrome 操作：执行 SSS-MAIN-01 的光标选择步骤，只执行允许的只读 SQL。
- 预期结果：语法错误与当前语句提示正常显示；有效 SQL 可独立选择和执行；未授权操作仍由既有权限规则拦截。
- 恢复/清理：退出测试账号。

### SSS-STATE-01 手动选择优先级

- 风险/目的：P0，确认错误文档中手动选区仍优先于当前语句提示。
- 初始路由与状态：查询页签已输入 D01，错误诊断可见。
- 测试数据：D01。
- Chrome 操作：跨行手动选中一段有效 SQL，点击“执行”；取消选区后把光标放在另一条语句中再次执行。
- 预期结果：存在非空手动选区时只执行选中文本；取消选区后恢复按光标当前语句执行；语法错误不会让两种目标都变成不可用。
- 恢复/清理：清空执行结果和查询页签。

## Cleanup

1. 清空并关闭未保存查询页签。
2. 恢复 Chrome 网络、窗口尺寸和测试账号状态。
3. 确认只执行了隔离数据源上的只读 SQL，没有遗留事务或数据变更。

## Skip Conditions

- 无可用隔离测试数据源时，只做语句提示框与按钮状态验证，执行结果场景标记为 SKIP。
- 无法安全模拟网络故障时，SSS-FAILURE-01 标记为 SKIP，并以源码检查确认本地回退不依赖语句切分响应。
- 移动宽度下产品若不支持完整 SQL 操作，只验证提示框定位和页面无非预期横向溢出，不点击执行。
