# HANA 结构编辑与对象脚本

## Purpose

验证 HANA 结构读取、表单编辑、SQL 预览、执行、回读闭环，防止无修改保存重建约束、默认值/注释不能清空、索引操作越过所属表权限以及对象脚本缺失主体。

## Scope

- SQL 工作台 `/#/sql`，HANA 新建/编辑表、对象右键菜单、SQL 预览弹窗。
- `editor/table/generateScript`、表编辑执行、`browse/actions/requestScript`、查询执行与对象刷新。
- 表/列、PK/UK/FK、普通索引、默认值、identity 新列、行存/列存、七类对象原生脚本。
- 不覆盖 HANA Cloud、全文/空间索引的图形化重建、任意原生 DDL 的解析、跨产品自动无损迁移。

## Preconditions

- `http://127.0.0.1:8222/` 本地服务可访问，@Browser 已登录；使用隔离 HANA 2.0 Platform tenant（可用 Express）。
- 部署本步的 HANA 插件、SQL 引擎、console/SDK/schema 运行包和 Web 资源，不能只替换旧插件目录内单个 JAR。
- OWNER 可创建测试 schema/对象并调用 `SYS.GET_OBJECT_DEFINITION`；另备仅表级 DDL、只读、无权限账号。
- HANA 仍默认隐藏；沿用本项目 HANA 验收 README 的隔离环境入口，不为测试开放生产入口。
- 使用每次唯一 schema 名，替换 `tests/datasource/hana/sql/10-structure.sql` 中的 `HANA_EDIT_TEST`；按区段准备，禁止整文件一键执行。

## Test Data

- D01：样本 CHILD/PARENT，列顺序 LABEL→ID→PARENT_ID→AMOUNT→CREATED_AT，两个独立 UNIQUE、一个 FK、identity、默认值和中文注释。
- D02：ROW_SAMPLE、IX_ROW_AB，包含复合索引与 DESC；另有 CHILD 的列存索引。
- D03：视图、触发器、过程、函数、序列、同义词；触发器字符串包含分号，用于检查主体未拆坏。
- D04：边界新列 NVARCHAR(1/5000/5001)、DECIMAL(38,38)/(38,39)，名称含空格、双引号、中文，默认字符串 `'O''Brien'`。
- D05：两个 schema 中同名索引分别归属不同表；只授权其中一张表 DDL，避免 schema 通配授权掩盖错误。
- 所有数据仅属于本次测试 schema；恢复或删除前核对名称和归属。

## Suites

### HSE-SMOKE-01 入口与字段（P0）

- 初始路由/数据：`/#/sql`，D01–D03 已准备，OWNER 登录。
- 操作：打开 CHILD 的编辑表页签，查看字段、主键、索引、外键、表属性；依次右键七类对象。
- 预期：列顺序不变，两个 UNIQUE 分别显示，索引唯一性和物理类型分开；表属性显示 COLUMN；各类对象存在“获取创建语句”。序列菜单可打开脚本；程序编译及未实现的图形化程序编辑不展示。
- 清理：关闭菜单与未编辑页签。

### HSE-MAIN-01 无修改与单项修改（P0）

- 初始路由/数据：`/#/sql`，新打开 D01 的编辑页签。
- 操作：先不修改点击“预览变更”；再分别清空表注释、列注释、LABEL 默认值，每次预览、执行、刷新、重新预览。
- 预期：无修改预览没有 DDL；清注释使用 `COMMENT … IS NULL`；清默认值使用 `ALTER … DEFAULT NULL`；不重写 identity、不删除/重建无关 PK/UK/FK；刷新后值正确且再次无修改预览为空。
- 清理：按样本恢复注释及默认值，刷新确认。

### HSE-MAIN-02 结构与索引（P0）

- 初始路由/数据：`/#/sql`，D01/D02 的编辑页签。
- 操作：分别新增/改名/删除测试列、修改列类型和可空性、增删一个 UNIQUE、修改 FK 映射、重排索引列；逐项预览并执行。对 ROW_SAMPLE 执行 ROW→COLUMN→ROW。
- 预期：仅目标约束变化；唯一约束使用 `DROP CONSTRAINT`，普通索引使用 schema 限定的 `DROP INDEX`；索引重排只生成一次删除和一次新建，顺序与预览一致。按样本回读 SQL 核对数据类型、列顺序、多个 UNIQUE 和表存储类型。
- 清理：恢复结构；涉及存储转换的验收表不放业务数据。

### HSE-MAIN-03 对象脚本（P0）

- 初始路由/数据：`/#/sql`，D03 对象列表。
- 操作：七类对象分别获取创建语句，与 HANA 原生 `SYS.GET_OBJECT_DEFINITION` 返回值比较；在隔离副本中按依赖顺序重建并回读。
- 预期：schema/引号、函数和过程参数、触发器定义、内部字符串分号、序列属性、同义词目标完整；空结果或权限不足明确报错。获取脚本成功与脚本回放成功分别验收。原生扩展语法若被工作台严格分析拒绝，记录具体语句，不能改用放宽权限/跳过审核来宣布通过；可在原生 HANA 客户端单独验证数据库等价性。
- 清理：仅删除本次副本；保留原对象供其余场景使用。

### HSE-BOUNDARY-01 默认值、长度与 identity（P1）

- 初始路由/数据：`/#/sql`，新建表页签，D04。
- 操作：预览长度 1、5000、5001；精度 (38,38)、(38,39)；默认值选择无默认值、空字符串、自定义 `0`、`'O''Brien'`、`CURRENT_TIMESTAMP`；新增 identity 列；单独修改已有 identity 注释，再尝试改变其类型/生成标记。
- 预期：合法边界不被截断，越界明确报错；SQL 字符串正确转义；新 identity 使用 BY DEFAULT；已有 identity 注释可改，其生成属性/类型改动明确拒绝，不能以无效 ALTER 假装成功。
- 清理：不执行越界/拒绝项，关闭新建页签。

### HSE-EXTREME-01 长名称与窗口（P2）

- 初始路由/数据：`/#/sql`，D04 的含中文、空格、双引号对象；D03 原生长脚本。
- 操作：分别在常见桌面与窄视口打开编辑详情、索引类型下拉和脚本弹窗；滚动至脚本末尾。
- 预期：脚本不截断，关闭/返回可操作；窄视口受工作台既有最小宽度限制时记录限制，不能把未显示内容判作通过。
- 清理：恢复原视口并关闭弹窗。

### HSE-REPEAT-01 重复操作与并发（P1）

- 初始路由/数据：`/#/sql`，D02，两个编辑页签。
- 操作：重复预览同一修改；快速双击执行；在另一页签修改后回到旧页签预览；刷新后再进入。
- 预期：无无关重复 DDL；重复创建/索引已不存在等数据库失败需显示真实错误；刷新后反映实际结构。不能把旧页签缓存当成数据库事实。
- 清理：刷新所有测试页签，按回读结构恢复 D02。

### HSE-FAILURE-01 部分失败与恢复（P0）

- 初始路由/数据：`/#/sql`，OWNER，D02 的可删除测试索引。
- 操作：在预览后由隔离测试的另一会话制造同名索引冲突，使删除成功而新建失败；恢复后刷新并重新创建。
- 预期：显示新建失败，回读明确缺少目标索引；不能声称 DDL 已整体回滚；修复后再次预览为空。断网/会话失效仅在工具支持网络模拟时执行，否则记录覆盖缺口。
- 清理：确认索引恢复，再关闭页签。

### HSE-LIFECYCLE-01 页面生命周期（P1）

- 初始路由/数据：`/#/sql`，D01。
- 操作：预览后返回、切换对象、刷新页面、重新打开表编辑；打开脚本弹窗后关闭重开。
- 预期：新加载数据与数据库回读一致，不混用其他表/schema 的属性或脚本；默认值、唯一性、索引列顺序不因重新打开而改变。
- 清理：关闭测试页签。

### HSE-PERMISSION-01 所属表授权（P0）

- 初始路由/数据：`/#/sql`，D05；分别以完整、仅表级 DDL、只读和无权账号登录。
- 操作：在查询窗口删除/重命名两个 schema 的同名索引；为未授权表配置阻断审核规则。随后由 OWNER 删除目标索引，再尝试执行旧语句。
- 预期：授权和审核按实际所属表匹配，不能按当前 schema 或索引名猜测；只读/无权账号不能执行；索引不存在、元数据查找失败明确阻断。普通 SELECT 不因本步新增索引元数据查询。
- 清理：恢复索引、测试授权和规则，恢复原登录账号。

### HSE-STATE-01 DDL 转换（P1）

- 初始路由/数据：`/#/sql`，D01 和仅 INTEGER/NVARCHAR/DECIMAL(18,4) 的简单测试表。
- 操作：先做 HANA→HANA DDL 转换，再逐个选择已声明目标；转换后返回源表编辑并无修改预览。
- 预期：同源转换保留列顺序、PK 名称、独立 UNIQUE/FK，不修改当前编辑对象；异构转换遇到已知不能保持的外键/生成列/键语义/精度/长度时明确拒绝。简单输出仍需在实际目标引擎执行回读；仅生成文本不算迁移等价通过。
- 清理：关闭预览；删除为实测新建的目标副本。

## Cleanup

关闭测试页签，恢复测试授权与审核规则；核对唯一 schema 名称后删除本次隔离 schema 及目标副本。不要执行样本中的清理语句删除任何非本次创建的数据。

## Skip Conditions

- 本地服务不可达：浏览器流程阻塞；可运行模块测试与临时编辑器/JDBC/权限解析探针，不能替代实库验收。
- 无 HANA 或目标转换引擎：执行、回读、原生脚本等价性保持未验证。
- 未登录：按 `frontend/AGENTS.md` 请用户在 @Browser 登录，不读取 Cookie/Token，也不切换浏览器绕过登录。
- 无隔离授权账号/审核配置：权限套件不得标通过；离线对象关系与规则域断言只证明解析输出。
- 网络模拟或视口能力不可用：明确记录对应覆盖缺口；不得用代码检查宣称已完成浏览器测试。
