# SQL 编辑器字体一致性

## Purpose

验证 SQL 工作台、工单、CI/CD 和管理日志中的 SQL Monaco 编辑器使用同一套字体规范，重点防止可编辑、只读和 Diff 编辑器因页面局部配置出现字号、字重、行高或字体族漂移。

## Scope

- 页面与路由：`/#/sql`、`/#/ticket/:id`、CI/CD 变更记录 SQL/Diff 弹窗、SQL 管理日志详情。
- 入口：SQL 工作台编辑区、工单 SQL 内容与任务“查看”、CI/CD 变更记录“SQL 变更”与 Diff、SQL 日志详情。
- 关联状态：SQL 编辑器初始化、内容切换、字号调整、只读预览、Diff 预览、刷新与重新进入。
- 关联源码：`frontend/src/components/editor/`、`frontend/src/views/sql/`、`frontend/src/views/ticket/`、`frontend/src/views/cicd/`。
- 不覆盖：SQL 语法解析正确性、自动补全内容正确性、JSON 编辑器字体和数据库执行结果正确性。

## Preconditions

- 本地 `DmAloneLauncher` 已启动，访问地址为 `http://127.0.0.1:8222/`。
- Chrome 已登录具备 SQL 查询、工单查看、CI/CD 变更记录查看和管理日志查看权限的账号。
- 至少有一个可进入 SQL 工作台的测试数据源、一条包含 SQL 的工单、一条包含 SQL 与 Diff 的 CI/CD 变更记录。
- 所有执行场景仅允许使用隔离测试数据库；字体检查不要求执行 SQL。

## Test Data

| 编号 | 数据说明 | 构造方式 | 唯一标识 | 清理方式 |
|---|---|---|---|---|
| D01 | 标准 SQL | 在 SQL 工作台输入 `SELECT 1;` | 无 | 清空未保存查询页签 |
| D02 | 多语言与长行 SQL | 输入包含中英文注释、数字、符号及超过视口宽度的单行 SQL | `codex_sql_font_<时间戳>` | 清空未保存查询页签 |
| D03 | 只读与 Diff 数据 | 使用已有工单及 CI/CD 变更记录 | 记录业务 ID | 无写入，无需清理 |

字体基准来自 `frontend/src/components/editor/sqlEditorTypography.js`：Menlo/Monaco 等宽字体、默认 14px、400 字重、21px 行高、0 字间距。

## Suites

### SEF-SMOKE-01 SQL 工作台默认字体

- 风险/目的：P0，确认用户最常用的可编辑 SQL 区使用全局字体基准。
- 初始路由与状态：进入 `/#/sql`，打开一个数据库查询页签。
- 测试数据：D01。
- 准备方法：选择测试数据源并创建空白查询页签。
- Chrome 操作：输入 `SELECT 1;`，检查编辑内容、行号、光标所在行和当前 SQL 语句提示框；读取 Monaco 可见文本的计算样式。
- 预期结果：编辑内容使用 Menlo；系统没有 Menlo 时按 Monaco、Courier New、monospace 顺序回退；默认字号为 14px、字重为 400、行高为 21px、字间距为 0；SQL 关键字高亮存在但不会通过粗体改变统一字重；当前 SQL 语句提示使用低对比度绿色细边、轻背景和 4px 小圆角，不显示高对比度直角硬框。
- 恢复/清理：关闭未保存查询页签。

### SEF-MAIN-01 可编辑、只读与 Diff 一致

- 风险/目的：P0，防止不同业务入口继续保留局部粗体或默认 Monaco 字体。
- 初始路由与状态：依次打开 SQL 工作台、工单 SQL 内容、CI/CD SQL 变更弹窗、CI/CD Diff 弹窗和 SQL 管理日志详情。
- 测试数据：D01、D03。
- 准备方法：记录各入口可稳定定位的业务对象。
- Chrome 操作：在每个入口检查相同 SQL 片段；分别读取可编辑、只读和 Diff 两侧 Monaco 文本的 `font-family`、`font-size`、`font-weight`、`line-height` 与 `letter-spacing`。
- 预期结果：所有 SQL Monaco 编辑器的默认计算样式均落在同一字体族，且为 14px、400、21px、0；Diff 左右两侧一致；页面没有通过局部 props 或 CSS 将 SQL 内容改回粗体；JSON 编辑器不受本规范影响。
- 恢复/清理：关闭全部弹窗并返回 SQL 工作台。

### SEF-BOUNDARY-01 多语言、符号与超长行

- 风险/目的：P1，确认统一等宽字体回退时中英文、标点和超长 SQL 仍可读。
- 初始路由与状态：SQL 工作台查询页签已打开。
- 测试数据：D02。
- 准备方法：将测试 SQL 粘贴到编辑器，不执行。
- Chrome 操作：检查中文注释、英文标识符、数字、引号、反引号和括号；横向滚动查看超长行。
- 预期结果：字符不乱码、不重叠、不被裁切；等宽英文字符对齐；中文通过系统回退字体正常显示；横向滚动不改变字体或行高。
- 恢复/清理：清空查询页签。

### SEF-EXTREME-01 视口与缩放

- 风险/目的：P1，验证字体统一后在常见桌面、平板和手机宽度不会导致工具栏或编辑区溢出。
- 初始路由与状态：SQL 工作台和一个只读 SQL 弹窗均可见。
- 测试数据：D02、D03。
- 准备方法：先保持浏览器缩放 100%。
- Chrome 操作：分别在 1440×900、1024×768、390×844 检查；桌面再检查 80%、100%、125% 缩放。
- 预期结果：编辑内容仍使用统一字体族；行号与内容基线对齐；工具栏按钮不因字体变化重叠；窄屏允许编辑器内部横向滚动但页面无非预期横向溢出。
- 恢复/清理：恢复 100% 缩放和原窗口尺寸。

### SEF-REPEAT-01 字号切换与多页签

- 风险/目的：P1，确认 SQL 工作台允许调整字号时只改变字号，不污染其他字体属性或只读编辑器。
- 初始路由与状态：SQL 工作台至少打开两个查询页签。
- 测试数据：D01。
- 准备方法：两个页签输入相同 SQL。
- Chrome 操作：在当前页签依次切换 12、16、20 字号并快速切换页签；随后打开工单只读 SQL。
- 预期结果：工作台字号按操作变化，字体族仍为全局规范且默认字重保持 400；编辑器行高随 Monaco 正常布局，无文本重叠；只读 SQL 默认仍为 14px，不被工作台字号操作污染。
- 恢复/清理：关闭测试页签。

### SEF-FAILURE-01 内容加载失败后的字体稳定性

- 风险/目的：P2，确认只读 SQL 请求失败与恢复不会导致编辑器以不同默认样式重新创建。
- 初始路由与状态：工单或 CI/CD SQL 预览已成功加载一次。
- 测试数据：D03。
- 准备方法：仅在隔离环境临时切换 Chrome 离线。
- Chrome 操作：离线后刷新预览，恢复网络并重试。
- 预期结果：失败走项目统一错误提示；恢复后重新创建的 SQL 编辑器仍使用全局字体规范，没有闪回粗体或 12px 默认值。
- 恢复/清理：恢复网络条件。

### SEF-LIFECYCLE-01 刷新与重新进入

- 风险/目的：P1，确认刷新、关闭弹窗和路由重进后的编辑器初始化一致。
- 初始路由与状态：SQL 工作台、工单 SQL 弹窗和 CI/CD SQL 弹窗均已至少打开一次。
- 测试数据：D01、D03。
- 准备方法：记录各入口。
- Chrome 操作：刷新 SQL 工作台；关闭并重新打开两个只读弹窗；通过侧边栏离开后重新进入。
- 预期结果：每次初始化均使用同一字体族和默认 14px/400/21px/0；没有旧 Monaco 实例残留造成双层文本或样式覆盖。
- 恢复/清理：关闭弹窗并返回稳定初始页面。

### SEF-PERMISSION-01 只读权限入口

- 风险/目的：P1，确认只读账号看到的 SQL 预览与可操作账号一致，且不会因操作按钮隐藏改变编辑器样式。
- 初始路由与状态：使用只读账号访问允许查看的工单、CI/CD 变更记录和 SQL 日志。
- 测试数据：D03。
- 准备方法：由管理员分配最小查看权限。
- Chrome 操作：分别进入三个只读入口并检查 SQL 文本样式和只读状态。
- 预期结果：SQL 内容不可编辑；字体仍为全局规范；隐藏执行、复制等无权限操作后编辑器宽度和文本基线不跳动。
- 恢复/清理：恢复测试账号权限。

### SEF-STATE-01 统一配置事实来源

- 风险/目的：P0，防止后续页面重新硬编码 SQL 字体。
- 初始路由与状态：源码工作区可读。
- 测试数据：不适用。
- 准备方法：无。
- Chrome 操作：完成页面目视验证后，结合源码检查所有 SQL Monaco 创建入口。
- 预期结果：所有 SQL Monaco 创建入口复用 `SQL_EDITOR_TYPOGRAPHY`；页面不传入另一套字体 props；唯一允许的运行时差异是 SQL 工作台用户主动调整字号。
- 恢复/清理：无。

## Cleanup

1. 关闭未保存查询页签和全部 SQL/Diff 弹窗。
2. 恢复测试账号权限、Chrome 网络条件、缩放和窗口尺寸。
3. 确认没有执行 SQL、创建工单或遗留运行中任务。

## Skip Conditions

- 缺少工单、CI/CD 或管理日志查看权限时，对应只读入口标记为 SKIP；仍需完成 SQL 工作台及有权限入口的计算样式验证。
- 缺少包含 Diff 的稳定变更记录时，Diff 浏览器场景可 SKIP，但必须以源码检查确认 Diff 编辑器复用全局配置，并明确浏览器覆盖缺口。
- 无法安全模拟断网时，失败恢复场景可 SKIP；不得在生产环境制造接口失败。
- 手机宽度下 SQL 工作台若产品明确不支持完整操作，只验证无页面级横向溢出和字体未漂移，不执行编辑操作。
