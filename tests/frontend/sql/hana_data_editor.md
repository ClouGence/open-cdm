# HANA 数据编辑与 SQL 导出回放

## Purpose

验证 HANA 行定位、值往返、批量部分失败及 SQL 导出回放，防止复合键漏列、默认值被 NULL 覆盖、精度丢失、截断数据被当作完整备份和失败行被标记成功。

## Scope

- `/#/sql` 表数据页，`fetchData`、`generateDml`、`saveData`；查询结果区的服务端 SQL 导出。
- SQL 编辑器粘贴回放；工单上传 SQL 文件的完整审核、执行与取消见第 12 步。
- 不把表数据页的本地 CSV 下载当作完整数据库备份。当前没有通用 CSV/XLSX 数据导入向导。
- 导出转换没有独立的页面取消入口；关闭结果页签不等于取消服务端转换。查询取消与转换线程中断分别验证。

## Preconditions

- 本地 `http://127.0.0.1:8222/#/sql` 可用，已登录测试账号；部署完整 console/SDK/schema、HANA、SQL HANA、plus-file-convert 和 Web 包。
- 测试 tenant 为约定的 Express SPS 08。HANA 默认隐藏，沿用测试环境已有受控入口；不修改生产数据源。
- 准备具备 QUERY/DML/EXPORT/SENSITIVE 权限的账号，以及仅查询、可导出但无敏感权限的账号；数据库账号有测试 schema 权限。
- 默认值、显式 NULL、复制行和全默认值行的通用行为按 [数据编辑默认值与 NULL](data_editor_defaults.md) 验证。
- 先阅读 [结果导出下载流程](query_result_export_download.md)；脱敏准备沿用 [HANA 血缘脱敏](../security/hana_lineage_masking.md)。

## Test Data

使用 [11-data-edit.sql](../../datasource/hana/sql/11-data-edit.sql)，把 `HANA_DATA_TEST` 替换为本次唯一 schema。通过 SQL 工作台按准备区段执行，失败样本与 DROP 不一起执行。

`EDIT_COLUMN` 覆盖 identity、DECIMAL(38,8)、TIMESTAMP、Unicode、NULL/空字符串、二进制和 LOB；`EDIT_ROW` 覆盖复合主键；`EDIT_UNIQUE` 覆盖两组独立唯一键；其余表覆盖无键、可空唯一键、视图和仅 identity 列。`EDIT_REPLAY` 是隔离回放目标。

## Suites

每个场景结束后刷新真实数据库核对状态；不要仅看临时网格。非破坏场景关闭页签即可恢复，写入场景删除本场景新增行或重新准备唯一 schema。

### HDE-SMOKE-01 / Smoke（P0）

- 初始状态：`/#/sql`，准备表已创建，完整权限账号。
- 操作：展开测试 schema，打开 `EDIT_COLUMN`、`EDIT_ROW` 的表数据页；打开新增、修改、删除的 SQL 预览。
- 预期：不出现 `$rowid$`；UPDATE/DELETE 包含完整主键；预览可以关闭而不改变数据库。
- 清理：取消预览，关闭页签。

### HDE-MAIN-01 / Main Flow（P0）

- 初始状态：`EDIT_COLUMN` 数据页；使用正常类型样本。
- 操作：新增一行，LABEL 不填写；再新增一行，对 LABEL 用右键“设置为 NULL”；再新增 LABEL 为空字符串的行。修改 AMOUNT、STAMP、BIN；保存后刷新。在 `EDIT_IDENTITY_ONLY` 新增空白行。
- 预期：分别回读默认文本、NULL、空字符串；identity 回读或刷新后可见，38 位数值和 `.1234567` 不丢失；十六进制 `00FF` 与空值不同；修改 identity 被禁用。仅 identity 的新增也生成一个新值。
- 清理：删除新增行，恢复原有值。

### HDE-BOUNDARY-01 / Boundaries（P0）

- 初始状态：`EDIT_ROW`/`EDIT_UNIQUE` 数据页，使用同 K1/不同 K2 的样本。
- 操作：修改和删除其中一行；编辑键列后保存并再次修改该行。尝试奇数长度 HEX、非法数字、8 位非零小数秒。打开无键表、可空唯一键表和视图。
- 预期：只变更一个目标；复合键不漏列，不拼接两个独立 UNIQUE；非法输入失败且原值不变。后三种对象可读且禁止数据编辑。
- 清理：恢复样本。失败输入取消编辑。

### HDE-EXTREME-01 / Extreme（P1）

- 初始状态：`EDIT_ROW` 页大小 2，按重复值 V 排序；另准备空表/单行表。
- 操作：遍历首页、下一页、末页，记录键集合；用原生 HANA 客户端准备超过显示长度的键和 LOB、超过缓存列限制的 LOB，再查看和导出。测试窄/宽视口、200% 缩放。
- 预期：静态数据分页无重复遗漏；键值被截断/脱敏时整页只读。SQL 导出对被截断的选中列明确失败，不产生可下载成功文件；完整缓存的 LOB 需在回放后比较长度/内容。时间输入显示小数秒；控件无新增遮挡。并发写入时 OFFSET 不承诺跨页快照。
- 清理：删除额外样本，恢复页大小与缩放。

### HDE-REPEAT-01 / Repeat And Concurrency（P1）

- 初始状态：两个页签打开同一行。
- 操作：另一页签先删除该行，再在旧页签保存修改；重复打开保存弹窗，检查请求与结果条目。
- 预期：影响行数为 0 时报告失败并要求刷新；不能伪报成功或修改其他行。未提供乐观锁版本控制，普通并发更新按数据库实际结果核对。
- 清理：刷新页签，重新准备被删除的行。

### HDE-FAILURE-01 / Failure And Recovery、State Consistency（P0）

- 初始状态：新增三行，第二行与第一行键重复。
- 操作：提交批量编辑；随后在独立重复场景模拟请求拒绝和断网（仅当 @Browser 支持）。恢复网络后关闭执行结果并刷新，重试尚未成功的行。
- 预期：第一行成功；第二行失败；第三行“未执行”。失败行不进入成功集合，仍可编辑。已成功行没有回滚，也不应随重试重复插入；最终数据库状态与结果条目一致。网络失败不能解释为数据库必然未提交，重试前先刷新确认。
- 清理：删除成功行，恢复网络。没有网络模拟能力则明确跳过相应分支。

### HDE-EXPORT-01 / Main Flow、Permission（P0）

- 初始状态：完整权限账号执行 `SELECT * FROM <schema>.EDIT_COLUMN ORDER BY ID`，查询完成。
- 操作：在结果区选择 SQL 导出，目标选择 HANA、表名填写 `"<schema>"."EDIT_REPLAY"`，导出全部行；按下载流程保存文件。打开文本，粘贴到 SQL 编辑器回放，再查询目标表。另测选列、offset/limit；无敏感权限账号重复导出含敏感列查询；只读账号尝试编辑。
- 预期：HANA 禁止合并多行 VALUES，文件为 UTF-8、逐行 INSERT；引号/分号不会拆坏语句，NULL/空值、数值、时间、二进制一致。脱敏账号导出的仍是脱敏结果，不能把此文件用作原值恢复。只读账号写入被拒绝。
- 清理：清空隔离回放表，删除本地测试文件，恢复脱敏配置。

### HDE-LIFECYCLE-01 / Lifecycle、Failure And Recovery（P1）

- 初始状态：长查询与大结果导出分别准备，使用隔离环境。
- 操作：取消正在取数的查询，重新查询；导出期间切换页签、关闭后重进，核对服务端状态。测试进程停止/转换中断后再次导出。
- 预期：查询取消后可重新执行；转换被中断或读取失败后不显示成功下载，部分 SQL 文件清理。没有页面转换取消入口时不把关闭页签记作取消成功；以日志和文件句柄检查验证服务端释放。
- 清理：停止测试查询，删除临时导出文件并恢复进程。

## Cleanup

确认目标是本次唯一 schema 后，单独执行样本末尾 DROP；恢复权限、脱敏规则、页大小及网络设置。删除本地导出文件，关闭本流程创建的页签。

## Skip Conditions

服务不可达、没有测试 tenant 或登录状态时跳过页面验收；登录缺失需用户在 @Browser 登录。缺少可控断网/进程中断能力时只跳过对应场景。替代验证为既有模块测试、真实缓存文件导出探针和 Vue 方法状态探针；这些不能替代 HANA 实库值往返及浏览器交互验收。
