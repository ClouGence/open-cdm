# SQL 收藏

## Purpose

验证收藏作为可复用 SQL 片段插入当前查询，保留周围正文、选区替换与撤销/重做；普通编辑不自动修改源收藏，也不产生收藏脏状态、保存修改或关闭确认。

## Scope

- 页面：`/#/sql`，编辑器右上角 SQL 收藏入口。
- 接口：`/api/entry/query/script/create|update|list|detail|delete`；update 仅供显式重命名或选择收藏保存时使用。
- 状态：普通查询正文、Monaco 选区和撤销栈、当前连接上下文；最近成功插入的收藏 ID 随当前查询草稿保存，仅用于保存弹窗的默认选择；收藏版本每次打开弹窗重新获取，不产生收藏编辑绑定。
- 不覆盖：团队共享、版本历史、回收站和 CI/CD；不执行收藏 SQL。

## Preconditions

- 本地 IDEA DmAloneLauncher 健康，前端使用已构建资源或开发服务器的实际地址。
- @Browser 已登录具备查询权限的测试账号，有可打开的隔离数据源。
- 跨类型验证需要两种类型的数据源；所有权验证需要第二个测试账号，不修改已有角色权限。
- 记录原页签、正文、连接、Catalog/Schema、结果区与视口，只在本轮临时查询编辑正文。

## Test Data

- SF01：唯一名称 `codex_sql_favorite_<唯一标识>`，正文 `-- 收藏片段\nSELECT '收藏 α';\nSELECT 418;`（实际换行）。
- SF02：另一个唯一名称及不同常量 SQL，用于连续插入、搜索和重命名。
- 基础查询：`-- before\nSELECT 1;\n-- after`，实际换行；记录逐字预期。
- 边界：空白正文、空白/129 字符名称、同名；大正文仅在隔离环境使用略大于 1 MiB 的确定性内容，不执行。
- 所有测试资产使用唯一前缀，清理时只删除本轮创建的收藏与查询。

## Suites

### SQL-FAV-SMOKE-01 创建、搜索、刷新和插入

- 目的/优先级：P0，验证收藏独立保存与主闭环。
- 初始状态：`/#/sql`，临时查询编辑器输入 SF01 正文。
- 准备：通过 SQL 收藏 → 保存 → 另存为新收藏，填写唯一名称后保存；SF02 独立创建。
- @Browser 操作：检查新建弹窗只有名称，不含覆盖方式；按唯一名称搜索、清空并刷新。回到基础查询，分别在文首、文中和文末点击收藏；每次先恢复基础查询，再设置插入点。
- 预期：列表仅含当前类型收藏，名称和时间可见；每次只在光标处插入完整片段，前后正文逐字保留；不新增/切换页签、不改标题/连接/数据库/结果、不执行 SQL。收藏入口无绿色脏点，浮层提供一个保存图标和刷新，保存菜单提供另存为新收藏及保存到已有收藏；保存必须显式选择目标，不按查询页签自动绑定。
- 清理：保留 SF01/SF02，恢复基础查询供独立场景使用。

### SQL-FAV-INSERT-01 选区、撤销、重做及重复使用

- 目的/优先级：P0，防止整篇替换、插入错位和撤销栈丢失。
- 初始状态：`/#/sql`，SF01 存在，临时查询包含基础查询。
- 准备：先独立创建 SF01，选中基础查询中的 `SELECT 1;`。
- @Browser 操作：点击收藏替换选区，撤销一次、重做一次；继续输入注释，再插入 SF02 与 SF01；用键盘移动选区并重复插入。
- 预期：仅选区被替换，前后注释保留；一次撤销恢复原选区正文，一次重做恢复整个片段；普通输入可独立撤销。连续插入按选择的位置累积，插入后光标位于片段末尾；全程没有自动保存提示或脏标记。
- 清理：恢复临时查询正文，保留原有用户页签。

### SQL-FAV-MAIN-01 源收藏隔离、重命名与删除

- 目的/优先级：P0，防止普通查询编辑更新收藏。
- 初始状态：`/#/sql`，独立准备 SF01 和 SF02，记录服务端原文（通过空临时查询插入并全选复制核对）。
- @Browser 操作：插入 SF01 后任意编辑，关闭临时查询，确认无收藏放弃对话框；另开空临时查询重新插入 SF01。更多菜单只有“插入编辑器”、重命名和删除；重命名 SF02，再搜索新名称、插入并比较原文。删除 SF02，核对已插入正文保持。编辑后选择“保存 → 另存为新收藏”创建新收藏，再重新插入 SF01。
- 预期：SF01 始终保持原文；查询编辑及关闭不发送收藏 update。新收藏不绑定查询，每次保存均需显式选择目标。重命名只改变选定收藏名称，原文不变；删除只改变列表，不改变编辑器或页签标题。保存期间不能重复提交或关闭弹窗。
- 清理：仅删除本轮新建收藏和临时页签。

### SQL-FAV-SAVE-01 另存为与保存到指定收藏

- 目的/优先级：P0，区分创建新收藏和显式覆盖已有收藏，防止保存到错误目标或丢失并发修改。
- 初始状态：`/#/sql`，独立临时查询，已通过“保存 → 另存为新收藏”准备 SF01/SF02；记录二者名称、正文和当前查询标题、连接。
- @Browser 操作：先向临时查询插入 SF01，再显式更新 SF02 让它排在列表首位。编辑临时查询为另一段多行常量 SQL，打开收藏面板点击保存图标，再选择“保存到已有收藏”；核对默认仍选中当前编辑器最近插入的 SF01，再按名称搜索并改选 SF02，确认保存。清空临时编辑器，重新插入 SF02 检查内容，再检查 SF01。刷新后重复读取 SF02。在桌面、平板和窄屏检查弹窗及选择菜单。
- 预期：顶部保留原图标，提示“保存”；点击出现“另存为新收藏”和“保存到已有收藏”两个选项，前者仅创建新收藏。保存弹窗标题“保存到 SQL 收藏”，首次加载完成后默认选中当前编辑器最近成功插入的收藏，允许搜索或下拉改选；未插入过收藏、对应收藏已删除或类型不符时保持未选择，不回退到列表首项；无收藏或未选择时按钮禁用，仅列出当前数据源类型的收藏；保存覆盖 SF02 正文但不改名称，SF01 不变。保存使用打开弹窗时的编辑器正文，不插入或执行 SQL，不改变查询标题、连接或页签数，不产生收藏绑定或关闭确认。
- 边界/恢复：取消、Esc/关闭再打开仍默认当前编辑器最近插入的收藏，不沿用上次手动改选的目标；翻页、搜索及版本冲突后刷新不自动替换用户选择；空 SQL 选择“保存到已有收藏”提示内容不能为空。搜索无结果及无收藏时不能提交；慢响应、关闭重开和快速搜索不得用过期列表覆盖当前结果；列表失败保留弹窗并可刷新重试。重复确认只提交一次，提交中禁止取消和关闭。
- 编辑器隔离：两个独立查询分别插入 SF01/SF02，来回切换并刷新后，各自的默认值保持独立；普通编辑、另存为或手动改选保存目标不改变最近插入记录。插入失败、过期响应或编辑期间取消插入不得更新记录。最近插入的收藏不在列表第一页时仍能默认选中；重命名后显示最新名称与版本，删除后保持未选择。
- 并发：两个测试标签分别打开同一个一次性收藏并选定；先在第二个标签显式改名/保存，再在第一个标签提交旧版本。旧提交应提示版本冲突、保留编辑器原文、取消目标选择并刷新可选列表；重新选择后才允许再次保存，不静默覆盖。删除目标后旧弹窗保存也必须失败且可重新选择。
- 清理：仅删除本轮创建的收藏和临时查询，恢复原正文、连接和视口；不执行 SQL，不修改已有收藏。

### SQL-FAV-LIFECYCLE-01 页签切换、刷新与旧草稿

- 目的/优先级：P0，防止恢复旧收藏编辑会话。
- 初始状态：`/#/sql`，临时查询已插入并修改 SF01；升级回归额外使用升级前保存的含收藏关联的草稿，不通过浏览器脚本写认证或存储。
- 准备：记录所有草稿的正文、标题和连接；旧未连接收藏草稿由隔离旧版本准备。
- @Browser 操作：切换页签再返回，刷新并恢复，核对正文、浮层及关闭行为；关闭后台临时页签和“关闭其他页签”，核对当前对象列表不闪白。旧未连接草稿重复编辑、新建收藏和关闭操作。
- 预期：普通查询草稿保持既有持久化语义；不会恢复收藏关联、版本基线或绿色脏点，不出现保存修改/放弃提示。旧草稿正文和标题保留，迁移已有类型用于收藏筛选；未连接时仍不能执行 SQL。关闭后台页签不改变当前连接或刷新对象列表。
- 清理：恢复原页签和搜索词，保留用户旧草稿。

### SQL-FAV-REPEAT-01 异步加载与失败恢复

- 目的/优先级：P0，防止迟到响应覆盖编辑或插入其他页签。
- 初始状态：`/#/sql`，SF01/SF02 已创建，临时查询包含基础查询。
- 准备：仅在工具支持时使用受控慢响应/断网；否则标记对应分支 SKIP。
- @Browser 操作：详情返回前连续选择两条收藏；另一次加载时继续编辑或切换页签。断网后加载、创建、重命名，恢复后主动重试；第二会话删除待插入的临时收藏后，在旧列表尝试插入。
- 预期：只有最新请求能生效；输入发生变化时提示已取消插入，切换页签后不插入，正文和选区没有被整篇替换。失败有明确提示，不产生后台写入或成功反馈，恢复后可重试。无权限或已删除详情不插入 SQL。更新冲突沿用服务端版本校验，不静默覆盖。
- 清理：恢复网络，删除一次性收藏，恢复原页签。

### SQL-FAV-BOUNDARY-01 名称、空正文与完整内容

- 目的/优先级：P0，验证创建与重命名边界。
- 初始状态：`/#/sql`，临时查询，独立创建 SF01。
- @Browser 操作：依次提交空白名称、同名、空白 SQL；检查名称输入最多 128 字符；创建含 Unicode、多行注释与空行的 SF02，清空编辑器后插入，全选复制逐字比较。隔离环境允许时重复略大于 1 MiB 正文的创建与插入，核对 UTF-8 长度和 SHA-256。
- 预期：非法数据不保存，合法多行内容完整保留；Monaco 按当前模型换行符插入，不额外添加分隔行；列表不返回正文。校验失败后可继续修改重试。
- 清理：删除成功创建的边界资产，恢复正文。

### SQL-FAV-EXTREME-01 分页、菜单和响应式

- 目的/优先级：P1，验证管理操作和布局。
- 初始状态：`/#/sql`，隔离账号准备 11 条唯一命名短收藏，或复用足够的现有列表仅做只读检查。
- @Browser 操作：搜索空结果、清空、翻页、滚动到底部，打开更多菜单并取消；在 1440×900、1024×768、390×844 重复检查浮层、新建和重命名弹窗，窄屏先通过页面按钮收起侧栏。打开菜单后点击外部或按 Esc，再打开字号面板后点击编辑器。
- 预期：筛选分页保留类型；浮层可滚动，保存和刷新图标可见，保存菜单的两个选项均可操作。长名称不撑宽；菜单、输入框、分页和底部按钮可见且可操作，无新增横向溢出；菜单随可用空间翻转且支持外部点击/Esc 关闭，字号面板不会遮挡收藏入口。
- 清理：删除本轮分页资产，恢复视口、侧栏与搜索词。

### SQL-FAV-PERMISSION-01 所有权与类型过滤

- 目的/优先级：P0，防止收藏越权或改变查询运行上下文。
- 初始状态：`/#/sql`，A/B 测试账号，两种类型的隔离查询，各自创建唯一收藏。
- @Browser 操作：在各类型查询下搜索相同唯一前缀，核对只出现当前类型；同类型插入时记录标题、页签数、Catalog/Schema、只读/事务与结果。B 尝试访问 A 的 detail/update/delete 仅在已有受控 API 测试能力时进行，不读取认证存储。
- 预期：异类型收藏不出现；插入保留全部运行上下文且不调用查询执行；所有权请求被拒绝、不改变收藏。
- 清理：各账号只清理自己的本轮资产，恢复账号状态。

## Cleanup

1. 仅删除唯一前缀的本轮收藏，关闭临时查询，保留原有页签和正文。
2. 恢复网络、窗口、侧栏、账号和查询搜索词。
3. 确认没有执行测试 SQL、修改源数据或遗留测试权限。

## Skip Conditions

- 无第二账号：所有权浏览器场景 SKIP，静态检查服务端权限和所有者条件，不能标为通过。
- 无第二数据源类型：跨类型场景 SKIP；仍须验证当前类型筛选及插入保持连接。
- 无旧版本隔离草稿：旧格式迁移仅做代码验证，浏览器分支 SKIP。
- 工具不能控制网络、慢响应或构造受控大正文：相关分支 SKIP，使用隔离方法级验证补充并说明边界。
- Browser、登录或服务不可用：依赖流程 BLOCKED，不能用构建替代验收。
