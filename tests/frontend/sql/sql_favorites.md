# SQL 收藏

## Purpose

验证用户可以把完整 SQL 保存为跨设备个人收藏，并安全地搜索、打开、修改、另存、重命名和删除；重点防止正文泄露到列表、所有权越界、版本覆盖、收藏载入改变连接、自动执行和脏页签静默关闭。

## Scope

- 页面与路由：`/#/sql`。
- 入口：SQL 编辑器右上角书签按钮。
- 关联接口：`/api/entry/query/script/create|update|list|detail|delete`、既有 `createSession`。
- 关联状态：`scriptId`、`scriptVersion`、`scriptSavedText`、`scriptName`、`scriptDsType`、当前查询页签运行上下文。
- 不覆盖：团队共享、标签/文件夹、版本历史、回收站和 CI/CD 文件发布。

## Preconditions

- 本地 `DmAloneLauncher` 已启动，访问 `http://127.0.0.1:8222/`。
- @Browser 已登录具备 `DM_QUERY_CONSOLE` 权限的隔离测试账号。
- 至少有两个可浏览的测试数据源：一个与收藏 SQL 类型相同；另一个类型不同。只执行只读 SQL。
- 第二浏览器会话或第二设备使用同一账号时，仅用于并发版本验证，不读取浏览器认证存储。

## Test Data

| 编号 | 数据说明 | 构造方式 | 唯一标识 | 清理方式 |
|---|---|---|---|---|
| SF01 | 标准多语句收藏 | 包含空格、注释、Unicode 和两条只读语句 | `codex_sql_favorite_<唯一标识>` | 从收藏菜单删除 |
| SF02 | 同名收藏 | 再次使用 SF01 名称保存 | 与 SF01 相同 | 请求应失败，无新增数据 |
| SF03 | 大正文回归 | 构造一份略大于历史 1 MiB 边界的确定性 UTF-8 正文，并记录长度与 SHA-256 | `codex_sql_large_<唯一标识>` | 删除收藏及对应正文文件 |
| SF04 | 冲突数据 | 两个会话打开同一收藏并分别修改 | SF01 | 保留一个最终版本后删除 |

大正文只验证一份略大于 1 MiB 的受控样本，不进行极端压力测试；名称边界来自 `varchar(128)` 与前端 `maxlength=128`。

## Suites

### SQL-FAV-SMOKE-01 创建、搜索和打开

- 风险/目的：P0，验证主闭环与服务端持久化。
- 初始路由与状态：打开一个已连接查询页签并输入 SF01。
- 测试数据：SF01。
- 准备方法：用唯一名称，避免依赖历史 ID。
- @Browser 操作：打开书签浮层，检查标题“SQL 收藏”右侧依次为新建收藏（文件加号）和刷新图标，两个图标与标题处于同一行并垂直居中；新建图标悬停/无障碍名称为“收藏当前 SQL”；检查带放大镜前缀的搜索框独占下一行，底部无重复按钮；点击新建图标收藏当前 SQL；按名称搜索、清空搜索，点击刷新并检查结果；记录查询页签数量和当前结果后单击列表项。
- 预期结果：标题左对齐，新建和刷新图标在右侧紧凑排列，搜索框占满浮层内容宽度；刷新保留搜索词并从第一页重新读取列表，加载期间刷新按钮禁用；无数据源定位操作。列表只展示名称和更新时间，不展示数据库类型或正文；标题不显示脚本数量，新建弹窗也不展示数据库类型或覆盖选项，删除展示项后没有残留空行；收藏 SQL 替换当前页签正文，页签数量不变、焦点不切换、不自动执行，完整 SQL 字节内容保持一致。
- 恢复/清理：保留 SF01 供后续场景使用。

### SQL-FAV-MAIN-01 覆盖、新建、重命名和删除

- 风险/目的：P0，验证全部 MVP 写操作和页签关联状态。
- 初始路由与状态：SF01 收藏页签已打开。
- 测试数据：SF01，以及内容、名称不同的另一条一次性收藏 B。
- 准备方法：在正文末尾增加 Unicode 注释，并记录两条收藏原有内容。
- @Browser 操作：修改当前页签后，确认标题右侧新增磁盘图标，悬停提示及无障碍名称为“保存当前修改”；点击该图标打开“选择要覆盖的 SQL 收藏”，确认通过可搜索下拉框选择目标，默认显示当前关联收藏，弹窗内没有单选列表或独立搜索框；先取消，确认没有保存，再重新打开并选择 B，核对下拉框选中名称，点击“确认”；重新打开 SF01 和 B 比较内容；另在临时查询中清空正文，点击磁盘图标应提示 SQL 内容不能为空且保持可重试；重新加载测试收藏后图标隐藏。确认更多菜单不存在“用当前 SQL 覆盖”；点击“收藏当前 SQL”，确认弹窗只有名称输入，没有覆盖方式或目标选择，再新建收藏。每次提交后核对关联状态；随后重命名和删除副本。
- 预期结果：搜索框下方没有“当前脚本有修改 / 保存当前修改”文字栏；新建、保存修改和刷新图标均与标题同排居中。未保存时，磁盘按钮右上角显示与书签入口一致的绿色角标，不遮挡磁盘图形，不影响提示和点击。选择目标和取消均不发起更新；确认后保留 B 的名称，仅替换 B 的 SQL 内容，SF01 的服务端内容保持原样，当前页签关联改为 B。保存期间确认、选择、搜索、分页与取消操作禁用，保存成功且正文未继续变化后图标与书签脏状态消失；再次修改后重新出现。保存当前关联时使用页签已有 `scriptVersion`，提交前不会刷新版本掩盖冲突；成功响应只更新发起页签，并以提交快照作为 `scriptSavedText`，请求期间继续输入仍保持脏状态；选择其他收藏时使用选中条目的版本；从其他目标切回当前关联收藏仍使用原页签版本；新建后关联切换到新 ID；重命名不错误提升正文版本；删除后名称可立即复用，页签正文保留并退化为本地草稿。
- 结果核对：取消后重新打开 A、B，确认仍为各自原文；重新编辑 A 并点击“确认”覆盖 B 后，再分别打开 A、B，确认只有 B 变更。覆盖弹窗只显示标题、收藏下拉框和底部操作按钮，没有额外说明文字或移除说明后残留的空行，桌面与窄屏下选择框及按钮均完整可见；所选名称仅在下拉框显示，底部按钮为“取消”和“确认”（英文为 Cancel 和 Confirm），重新打开弹窗默认选中当前关联收藏；下拉框支持键盘方向键与 Enter 选择，选择后搜索词清空，再次展开可以浏览全部当前页选项。每次核对都等待详情加载完成，避免把上一条收藏的编辑器内容当作结果。
- 恢复/清理：删除副本、原收藏和 B，只关闭本轮新建的临时查询页签；恢复原先选中的页签、数据源搜索词和视口。

### SQL-FAV-BOUNDARY-01 名称、空 SQL、Unicode 与大正文

- 风险/目的：P0，验证真实契约边界。
- 初始路由与状态：普通查询页签。
- 测试数据：SF02、SF03。
- @Browser 操作：依次尝试空白名称、129 字符名称、空白 SQL、同名和含非 ASCII 正文；再通过真实编辑器输入一份略大于历史 1 MiB 边界的确定性正文，完成新建、覆盖、重新打开，并分别记录提交前与读取后的 UTF-8 长度和 SHA-256。
- 预期结果：空白/超长名称、空白 SQL 和同名不可保存；大正文不因 SQL 收藏业务限制被拒绝，新建与覆盖成功，重新打开后长度和 SHA-256 与对应提交内容一致；列表响应不包含正文或大小上限字段。
- 恢复/清理：删除成功保存的边界收藏。

### SQL-FAV-EXTREME-01 分页、空列表和视口

- 风险/目的：P1，验证列表分页与浮层布局。
- 初始路由与状态：隔离账号可创建至少 11 条短收藏。
- 测试数据：按 `codex_sql_page_<唯一标识>_<序号>` 创建。
- @Browser 操作：验证空搜索结果、单条列表、跨页及滚动列表底部条目；分别在 1440×900、1024×768 和 390×844 视口核对未修改及已修改状态下的标题图标不换行、不遮挡搜索框（窄屏先通过页面按钮收起数据源侧栏，复测后恢复），再打开列表项右侧“更多”，确认没有覆盖入口，进入重命名和删除确认入口后取消；展开覆盖目标下拉框，输入搜索词、清空搜索、使用下拉菜单底部分页并选择下一页收藏，搜索到空结果时检查已选目标仍明确展示；分别在上述三个视口检查下拉框和菜单不超出视口、长名称不会撑宽，以及底部确认按钮完整可见；另外展开编辑器右上角字号面板（"T" 按钮）后点击编辑器正文区域，再展开收藏浮层。
- 预期结果：分页稳定按更新时间和 ID 降序；覆盖下拉框分页和搜索独立于收藏浮层，翻页或搜索不清除已选目标；选择后下拉框收起并显示名称，重新展开可浏览未筛选列表；空态明确；收藏主浮层可滚动且不遮挡核心操作，无非预期横向溢出；单条、底部及滚动后的“更多”菜单完整可见、可点击，并根据视口空间上下翻转且不越过屏幕边缘；外部点击、Esc、列表滚动到触发项不可见及组件卸载均能清理菜单；字号面板在点击面板外部后自动收起，不会持续悬浮遮挡同区域的收藏按钮。
- 恢复/清理：删除分页测试收藏并恢复窗口尺寸。

### SQL-FAV-REPEAT-01 异步加载与重复提交

- 风险/目的：P0，防止重复页签和重复资产。
- 初始路由与状态：SF01 已存在。
- 测试数据：SF01。
- @Browser 操作：在详情请求尚未返回时连续选择两条收藏；等待期间切换页签并继续编辑；发起对收藏 A 的新建后关闭弹窗并主动加载收藏 B；覆盖确认提交期间关闭入口禁用，重复点击确认只提交一次；覆盖目标搜索请求未返回时连续修改关键词、取消后重开，确认过期响应不覆盖最新列表；在查询运行/停止状态时选择收藏。
- 预期结果：只有当前页签上最新请求可以生效；旧响应、已切换页签响应和用户后续编辑均不被覆盖；A 的保存可在服务端成功，但其旧响应不得把当前页签从 B 重新绑定回 A；运行/停止期间载入只替换正文及收藏关联，不改变已提交查询、会话或执行状态；保存响应只更新发起页签；若其收藏关联已变化，不得重新绑定；提交期间产生的新正文保留脏状态；覆盖弹窗切换查询页签后关闭；服务端版本和唯一约束阻止重复或并发覆盖。
- 恢复/清理：恢复 SF01 为单一稳定版本。

### SQL-FAV-LIFECYCLE-02 关闭确认与对象列表稳定性

- 风险/目的：P0，防止关闭图标冒泡为页签切换、列表加载遮罩在确认遮罩上闪白，以及关闭后台页签误刷新当前列表。
- 初始路由与状态：普通查询页签 A 显示非空表列表；另有普通页签 B。记录 A 的标题、连接、表搜索词、分页与选中表。
- 测试数据：仅使用唯一命名的一次性收藏 SF01，不修改或删除用户已有收藏，不执行测试 SQL。
- @Browser 操作：在 A 加载 SF01 后编辑，点击页签关闭图标；从点击前开始连续采集页面帧及对象列表 Loading 可见性，覆盖确认框出现到稳定的过渡。选择取消，核对正文、标题及对象列表状态。再次关闭并放弃，验证只关闭 A；重新打开 A、载入 SF01，确认仍是上次已保存正文；通过收藏浮层保存修改仍可正常工作。另验证普通未修改查询直接关闭。
- @Browser 操作：保持 A 当前且列表稳定，关闭未修改的后台 B；再对后台脏收藏 B 发起关闭并取消或放弃。分别测试页签栏关闭图标与右上页签下拉列表中的关闭图标；使用 A 的“关闭其他页签”菜单，确认不重新加载 A。主动切换到另一查询以及点击表列表刷新，确认必要加载仍正常。
- 预期结果：弹出确认框仅有正常的模态遮罩过渡，表列表不出现新 Loading 或白色加载遮罩，不清空或重挂载；取消后正文与搜索、分页、选中表保持。放弃不更新收藏；关闭确认恰有取消和放弃两个操作，不发出收藏更新请求；普通未修改查询无收藏确认。关闭后台页签、取消/放弃后台关闭、关闭其他页签不改变当前页签、连接和对象列表，不错误清理当前结果缓存；真正关闭当前页签时正常切换到相邻页签并加载其列表。
- 恢复/清理：正常删除一次性收藏及本轮临时查询页签，保留原有页签和收藏；恢复窗口尺寸。

### SQL-FAV-PERMISSION-01 所有权与执行权限隔离

- 风险/目的：P0，防止通过脚本 ID 越权或绕过数据源权限。
- 初始路由与状态：账号 A 创建 SF01，账号 B 具备查询页面权限但不是所有者。
- 测试数据：SF01 的服务端 ID 仅通过测试准备记录传递，不写入本文档。
- @Browser 操作：账号 B 尝试 detail/update/delete；账号 A 在普通查询页签载入收藏并主动执行。
- 预期结果：账号 B 所有请求均表现为不存在且不改变文件或索引；载入不展示收藏专属数据源选择，执行仍走普通查询工作台既有连接与权限校验。
- 恢复/清理：账号 A 删除 SF01，恢复账号状态。

### SQL-FAV-STATE-01 运行上下文、跨类型切换与跨设备冲突

- 风险/目的：P0，验证运行态不持久化和乐观锁。
- 初始路由与状态：两个会话打开同一 SF04。
- 测试数据：SF04。
- @Browser 操作：记录已连接页签的连接、Catalog/Schema、事务/只读和已有结果；先输入未保存正文，再单击同 `dsType` 收藏，随后单击不同 `dsType` 收藏；检查 SQL 全文和页签数量。随后由会话 A 更新收藏，会话 B 打开覆盖选择弹窗，搜索或刷新列表后仍选择当前关联收藏并确认，用旧版本触发冲突；另验证选择其他目标后该目标被另一会话修改也会冲突，并分别验证加载服务端版本与新建收藏。
- 预期结果：两种加载都直接覆盖当前编辑器完整 SQL，无二次确认、无数据源选择、不新建或切换页签、不自动执行；顶部实际可见的查询标题、原连接、Catalog/Schema、事务、只读、会话和历史结果保持不变。收藏关联、版本和已保存正文基线与所选收藏一致。B 收到冲突且不能覆盖 A；加载服务端版本仅在目标页签未继续编辑时生效，新建收藏产生新 ID。
- 恢复/清理：删除 SF04 及副本，关闭两个会话的测试页签。

### SQL-FAV-STATE-02 旧未连接页签恢复

- 风险/目的：P0，移除绑定流程后旧草稿仍能使用。
- 初始路由与状态：已有旧版未连接收藏或本地草稿页签，无 node/sessionId。
