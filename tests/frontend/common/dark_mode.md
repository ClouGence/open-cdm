# 浅色与深色外观

## Purpose

验证 CloudDM 内置主题切换、刷新持久化和主要工作流的颜色一致性。

## Scope

- 工作台、SQL 全屏页、登录与初始化页的主题入口。
- 导航、表格、表单、下拉、弹窗、提示、Monaco 编辑器和查询结果。
- 不改变数据源、权限、审批或 SQL 执行行为；不使用浏览器自动反色模拟主题。

## Preconditions

- 本地后端和 Worker 就绪，前端使用当前源码开发服务。
- 打包入口 `8222` 也必须复查：根据当前 IDEA 运行配置确认实际资源目录（可能是 `frontend/out/production/resources`，也可能是前端 JAR），同步本次构建结果并重启。比较 HTTP 返回的入口资源引用及 JS/CSS 哈希与本次构建产物一致；仅 `all_build.sh web` 或服务重启成功不能证明页面使用新资源。
- @Browser 使用现有测试账号；只读查询使用已授权的本地隔离 MySQL 数据源。
- 不读取浏览器存储、Cookie 或令牌；通过页面按钮、刷新及路由确认持久化。
- 初始化全流程仅使用未初始化的隔离环境，不重置现有开发库。

## Test Data

- 空白临时 SQL 查询，内容为 `SELECT 1 AS theme_check, '中文' AS label, CAST(NULL AS CHAR) AS optional_value;`。
- 在线 SQL 工单、数据源新增表单、数据源类型选择弹窗；不提交业务表单。

## Suites

### THEME-SWITCH-01 入口、键盘和持久化

- 优先级/目的：P0，保证可访问切换和用户选择优先。
- 操作：从工作台及 SQL 页打开外观菜单，依次选择浅色、深色、跟随系统；通过 Tab 聚焦入口，按 Enter 打开，再按向下键进入选项，用方向键及 Enter 选择；立即刷新，再进入其他页面。选择跟随系统后变更测试系统外观，再选固定模式并重复系统外观切换。
- 预期：入口标签说明当前选择；菜单只显示太阳、月亮、显示器三个图标，悬停分别提示浅色、深色、跟随系统；当前项高亮，选择后关闭。焦点可见，主题立即切换，背景、文字、表格、弹层和编辑器不各自渐变而短暂深浅混杂。跟随系统时实时响应系统外观，固定模式时不受影响。刷新、全局配置加载及登录页访问不覆盖选择；快速交替切换后以最后一次选择为准，菜单、悬停和展开动画随后仍可用。切换不丢失查询正文和表单输入。图标为 18px、正文色描边，与相邻操作图标对齐。
- 清理：恢复原偏好、页签及查询正文。

### THEME-COMPONENTS-01 导航、表单、弹窗和状态

- 优先级/目的：P0，防止浅底残留和状态颜色失效。
- 操作：深色下检查侧栏“数据访问”的锁图标，对照菜单文字及相邻单色图标，分别悬停和展开；打开实例列表、新增数据源表单、类型选择弹窗及下拉；打开工单详情和创建相似工单页；查看查询结果分页栏与实际执行内容弹层；进入 CI/CD 查看启用、禁用、归档状态及可访问的详情/进度节点。切回浅色对照。
- 预期：“数据访问”锁图标跟随菜单文字颜色，普通、悬停和展开状态没有写死的暗灰填充，不显示为禁用状态；主要表面、正文、面包屑、图标、边框及禁用状态可辨；成功/警告/错误保持不同语义色，弹层与页面一致，无亮白内容区，状态标签使用深色语义底色而非浅色胶囊底色。深色描边主按钮（如查询）的边框与实心主按钮底色统一为 `#238636`，文字保留亮绿色，悬停、聚焦后边框不恢复亮绿；分页当前页及其悬停状态、启用开关的底色与边框也统一为 `#238636`，关闭和禁用状态保持原有区分。浅色布局和操作保持正常。
- 清理：取消弹窗，离开未提交表单，不创建或编辑数据源。

### THEME-EDITOR-01 SQL 编辑器和结果

- 优先级/目的：P0，验证已打开和后创建编辑器都跟随主题。
- 操作：新建临时查询，输入只读 SQL，切换两种主题并执行；在两种主题下分别新建编辑器；查看在线工单只读正文与可用的 SQL Diff。
- 预期：语法关键字、字符串、注释、光标、选择区、行号、查询结果及 NULL 均可辨；切换不改变 SQL。深色下全局实心主按钮（含执行、新增、提交和弹窗确认）统一使用 `#238636` 绿底与边框、浅色文字/图标，悬停和聚焦不恢复亮绿，避免过暗或大面积亮绿底；浅色保留原有主按钮样式，连接断开或执行中仍按原逻辑禁用。新编辑器不会把其他编辑器重置成浅色；只读与 Diff 使用同一全局主题。
- 清理：不执行写入 SQL，不审批工单；只关闭本轮临时查询。

- 预期：侧栏实例图标、查询页签及页签下拉列表的关闭图标、单色对象及刷新图标跟随正文颜色，两种主题下均清晰；彩色数据源、字段类型及状态图标保留语义色。选中背景不遮蔽图标；刷新后仍使用选定主题，查询正文不变。采样截图用于检查可见残留，不作为逐帧闪白检测或帧率基准。
- 恢复/清理：关闭对象类型菜单、收起本轮展开的表，恢复视口及原主题，不修改数据库对象与查询正文。

- 初始路由与状态：已登录具有页面查看权限的测试账号，深色模式，从实例页进入；使用现有只读记录，不新建业务对象。
- 页面范围：

  - 查询机器列表、安全规则、规则模版及已有规则的只读详情。
  - IM 配置、Git Ops、审批配置、SSO 的列表与新增表单。
  - 个人资料/安全、偏好设置四个分组、AI 配置及其新增弹窗。
- 操作步骤：逐个导航分组打开页面；打开可用的新增表单、角色权限树、账户授权和批量授权；打开查询集群新增弹窗及地域选项。进入规则模版新增页，打开“选择数据源”；查看已有规则脚本。进入环境页和已有工单详情。检查后取消弹窗或导航离开，不点击创建、保存、授权预览、应用、测试连接或审批执行等业务操作。
- 预期结果：
  - 主要背景、类型选择卡片、权限目录、拓扑节点、缩放工具及数据源范围控件均使用深色表面；正常、选中和不可用状态可辨。

  - 规则脚本整块不降低透明度；语法着色、行号和滚动区可读。阻塞/错误使用红色，警告使用琥珀色，成功使用绿色，不能统一染成品牌绿色。
  - CloudDM 单色标志在工单、审批和其他深色背景中可辨，第三方彩色品牌图标保持原色。
  - 切回浅色后控件边界、选中态、文字与脚本仍可读；在 1440×900、1024×768、390×844 复查角色/规则表单和集成类型选项的布局，不出现新遮挡。
- 恢复/清理：取消所有未提交表单和弹窗，恢复初始外观、语言和视口，不修改账号权限、集成配置或业务记录。

### THEME-CUSTOM-CONTROLS-01 自定义表面与选项状态

- 优先级/目的：P0，防止仅组件库控件适配，业务自定义按钮、原生输入和传送弹层保留浅色背景。
- 初始路由与状态：本地工作台深色模式；管理员通过账户列表进入可授权测试账号的授权页。普通账号的权限申请入口需要另用具备该入口的测试账号，不通过修改身份或权限绕过。
- 测试数据/准备：现有测试账号、已有发布流；新增实例只填写非敏感临时内容，不提交、不测试连接、不输入证书或 SSH 密钥。
- 操作步骤：
  1. 在账户授权页依次选择永久、一天、一周、一月、一年、自定义，打开日期弹层；仅查看，离开前不点击授权预览或提交。
  2. 打开实例新增类型弹窗，选择 MySQL，检查常规、选项、SSH/SSL、高级；打开类型切换弹窗和 SSH 设置，进入新建 SSH 草稿后取消，不编辑现有配置。检查 SSL 证书输入弹窗的空白文本域。
  3. 切换 MaxCompute 新增表单，打开 Endpoint 的公网/VPC 和地域列表，查看选中项，取消表单；驱动状态详情按当前真实状态查看，不为制造状态触发下载或修改驱动。
  4. 打开 CI/CD 新建发布流类型弹窗，切换单一发布流与编排选项。进入创建表单，查看变更类型选中态、禁用 Schema 和配置摘要；查看编排表单中的按钮、检查器与节点操作。离开未提交表单。
  5. 从已有发布流详情进入配置项，检查配置行、已配置/未配置状态；分别打开回调配置和 IM 通知配置，切换未保存的通知渠道后取消。
  6. 从工单列表打开已有完成与失败的 SQL 工单，查看任务执行汇总、SQL 执行行和可用的校验详情；只查看，不重试、执行或审批。完成状态使用深绿成功底色，失败使用深红错误底色，校验条目与行号区域不残留白底。
  7. 切回浅色并重复关键选项，随后切回深色并刷新。1440×900、1024×768、390×844 下复查授权选项、实例表单、发布流类型弹窗。
- 预期结果：普通、选中、悬停及禁用状态可辨，时间选项不出现白底或浅绿底；表单和 SSH 左右面板、证书文本域、Endpoint 传送菜单均为深色表面。驱动准备/未知/错误分别保持成功/警告/错误语义底色和可读文字；发布流配置行、通知渠道和状态标签不出现浅色块。选择框占位文字使用弱化正文色，不显示红色。切换主题不改变表单内容、业务状态或布局尺寸；浅色保留其原有样式。
- 恢复/清理：取消所有弹窗，不保存授权、数据源、SSH 或发布流配置；恢复原主题与视口。未能触达的驱动下载/错误状态、普通账号权限申请和证书分支应明确报告覆盖缺口。

### THEME-PERMISSION-TREE-01 权限树文字与勾选状态

- 初始路由与状态：深色模式，管理员从账号列表进入隔离测试账号的资源授权页；选择一个有权限项的实例或库。权限申请页通过正常入口复查同类树，不伪造账号身份。
- 数据与准备：使用本次带唯一前缀的测试账号；仅在未提交草稿中选择一个查询权限，不授予共享账号权限。
- 操作：检查普通与选中节点的文字、展开箭头和空白复选框；勾选一个叶子观察绿色勾选及父级半选，再取消。进入授权预览查看只读/禁用状态，返回草稿；批量移除预览中检查撤销项与追加项的红绿语义。浅色、深色交替切换并刷新，在 1440×900、1024×768、390×844 下复查。
- 预期：正常节点与背景有清晰对比，普通文字不为黑色；复选框未选时使用深色表面，选中/半选时使用主题强调色，勾选标记清楚。只读状态仍可辨认，增删项保持错误/成功语义色；切换主题不丢失当前资源、勾选草稿或预览状态，不新增页面级横向溢出。
- 恢复/清理：取消未提交的勾选草稿，恢复原主题与视口；权限提交仅随已明确授权的独立功能测试进行。

- 恢复/清理：取消申请和弹窗；取消表编辑并确认丢弃草稿，关闭本轮新建表页签，保留原查询；恢复原主题和视口。
