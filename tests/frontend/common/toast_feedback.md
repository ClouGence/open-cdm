# 全局消息提示

## Purpose

验证统一消息提示的关闭按钮位于容器内、没有圆形边框，避免共享提示组件的样式作用域失效。

## Scope

- 全局 `SonnerToast.vue` 和 `utils/toast.js` 产生的成功、警告、错误及信息提示。
- 只调整提示关闭按钮和正文避让；不覆盖居中确认弹窗或依赖库内部实现。

## Preconditions

- 本地 IDEA Alone 后端健康，前端开发服务使用实际打印的地址。
- @Browser 已登录测试账号，可访问 SQL 工作台及一个隔离数据源；不执行 SQL。
- 原查询、正文、页签、语言和视口已记录。

## Test Data

- 创建独立空临时查询，不输入 SQL；SQL 收藏菜单的“保存到已有收藏”会触发内容不能为空警告，无业务写入。
- 可用时通过已有复制操作触发成功提示，通过已有表单只触发必填校验，不提交业务记录。
- 长文本或多条提示仅使用既有安全的页面校验，不通过浏览器脚本调用 store、组件或应用 API 伪造状态。

## Suites

### TOAST-CLOSE-01 容器内关闭与正文避让

- 目的/优先级：P0，避免关闭按钮越出提示边界或压住正文。
- 初始状态：`/#/sql`，独立空查询，原页签及正文保持。
- 准备：打开 SQL 收藏 → 保存 → 保存到已有收藏，触发空内容警告；不执行 SQL。
- @Browser 操作：观察提示并读取其与关闭按钮的可见边界；检查按钮普通和悬停状态，点击关闭。
- 预期：关闭按钮完全位于提示框内，顶部和右侧各留 8px，按钮无圆形边框和默认白色底；正文右侧预留空间，不与按钮重叠。点击后对应提示消失，不影响查询正文或其他提示。
- 清理：关闭本轮临时查询，不改动原查询。

### TOAST-CLOSE-02 键盘、重复及自动消失

- 目的/优先级：P1，确保样式修改不破坏交互。
- 初始状态：空临时查询，已触发一条校验警告。
- 操作：用 Tab 将焦点移至关闭按钮，核对可见焦点后按 Enter/Space；重复触发两条提示，分别关闭，再等待新提示自动消失。若存在安全的成功、错误或信息触发入口，重复检查。
- 预期：焦点可辨认，键盘可关闭；关闭一条不误关其他提示，不自动提交表单；未交互的提示仍按原有时长消失，重复触发可再次关闭。加载中提示遵循原有不可关闭规则。
- 清理：关闭测试产生的提示和临时查询。

### TOAST-CLOSE-03 视口与生命周期

- 目的/优先级：P1，防止窄屏越界及刷新后样式丢失。
- 初始状态：`/#/sql`，临时查询，使用相同校验警告。
- 操作：分别在 1440×900、1024×768、390×844 触发提示，检查关闭按钮与正文；刷新并重新触发。
- 预期：所有宽度按钮均在提示容器内，无圆形边框、裁切或新增横向溢出；刷新后样式保持，关闭仍生效。
- 清理：恢复原视口和查询，关闭测试标签。

## Cleanup

- 关闭本轮临时查询及提示，恢复原有正文、页签和视口；不保存收藏，不执行 SQL，不修改数据源或权限。

## Skip Conditions

- 缺少相应安全提示入口时，错误/信息/加载和长文本分支标记 SKIP，检查它们均复用同一组件及关闭按钮类，不宣称页面实测。
- 缺少可访问测试数据源、登录状态或内置浏览器时，依赖场景 BLOCKED；不得用浏览器脚本伪造提示替代真实入口。
