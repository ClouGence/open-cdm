# 描述与说明浮层

## Purpose

统一描述、实例 ID、字段说明与公共表格完整文本浮层，防止固定尺寸造成大块留白、内部滚动条、窄屏溢出和多余复制按钮。

## Scope

- 实例列表 `/#/datasource`、环境 `/#/env`、审批配置的团队页签 `/#/integrations/approval`。
- 数据源新增页 `/#/datasource/add?dsType=Kafka`、`dsType=ElasticSearch` 的字段说明；实例参数配置中的参数说明；SQL 对象属性中的字段说明。
- 工单详情目标数据库路径的悬停浮层，使用全局 `description-popup` 样式。
- 安全规则及规范修改冲突弹窗中的环境描述；工单列表和详情的描述回归见 [ticket_detail.md](../ticket/ticket_detail.md)。
- 公共 `DmTable` 的 `tooltip` 文本列，包括审批团队描述及管理日志完整文本。
- 所有页面 View UI Tooltip/Poptip 和 Ant Design Tooltip/Popover 的共享白色表面、文字及箭头颜色。
- 关联源码：`styles/hover-popover.less`、`styles/description-popover.less`、`components/ui/DmTable.vue`、`components/form/UiFormField.vue` 及对应页面。
- 不覆盖 SQL、工单编号、连接配置和下载链接等独立复制功能；不修改审批、安全规则或数据源配置。

## Preconditions

- 使用已登录测试账号的 [@Browser](plugin://browser@openai-bundled) 内置浏览器；本地后端和前端开发服务器正常运行。
- 账号具有对应页面的查看权限；数据源字段说明可在新增表单中查看，无需连接或提交。
- 优先使用已有数据，只读验证；没有独立测试环境时不得修改共享团队、实例、环境和安全规则来构造长描述。
- 安全规则冲突弹窗仅在隔离环境按对应功能流程构造，不为验证浮层而强制应用或保存规则。

## Test Data

- 短描述：已有一字或短名称描述；空描述：已有未填写描述的环境或实例。
- 长描述：已有被表格截断的团队或环境描述；参数和字段说明使用后端实际返回的 HTML、列表或多行说明。
- 连续文本：操作审计已有超出列宽的 JSON 日志唯一信息，不记录敏感内容或凭据。
- 超长、多行及 Unicode 文本：仅在隔离环境按实际字段长度限制，通过正常页面创建带 `codex_description_<唯一标识>` 前缀的临时对象；限制来自对应表单和后端，不猜测长度。

## Suites

### DP-SMOKE-01 页面入口与完整内容

- 风险/目的：P0，确认各描述入口仍可用，统一浮层不影响原操作。
- 初始路由与状态：从侧边栏进入实例、环境，再进入集成 / 审批配置 / 团队；另从工单列表打开已有 SQL 工单详情；等待页面完成加载。
- 测试数据及准备：使用已有短、长、空描述，不保存任何修改。
- @Browser 操作：逐一悬停实例名称、环境描述、被截断的团队描述，以及工单详情的目标数据库路径；移入浮层选择文字，再移出关闭。
- 预期结果：白色浮层展示完整原文（实例名称悬浮改为显示对应完整数据源 ID，名称下方不常驻显示 ID，编辑图标保留）；宽高随内容自然变化，短文本不占固定大宽度；工单详情的目标数据库路径复用相同白色浮层，不出现单独的深色 Tooltip；没有内部滚动条或复制按钮；鼠标进入浮层后保持可见，文字可以选择。公共表格中未截断的单元格不弹出冗余浮层；显式描述入口内容为空时不弹出空浮层；实例无描述时仍可悬浮名称占位文字查看非空 ID；实例原编辑入口仍可见。
- 恢复/清理：关闭浮层，不改变数据。

### DP-MAIN-03 实例 ID 悬浮查看

- 风险/目的：P0，实例列表收起第二行 ID，但仍能按行查看真实标识。
- 初始路由与状态：`/#/datasource`，已有名称不同的两条实例以及无描述实例（存在时）。
- 测试数据及准备：记录现有实例名称、ID，不新增或修改配置。
- @Browser 操作：检查名称下方不再常驻 ID；悬浮两行名称，核对各自 ID；检查无描述行和旁边的编辑入口；刷新后重复，在 1440×900、1024×768、390×844 下检查浮层。
- 预期结果：列表只显示类型图标、名称和原有编辑入口；白色 `description-popup` 显示对应行完整 ID，换行自适应、无内部滚动条及复制按钮；无描述但有 ID 时仍可查看；不同记录不串行；名称与编辑入口未出现布局遮挡。
- 恢复/清理：移出浮层，恢复视口，无数据写入。

### DP-MAIN-02 全局 hover 组件外观

- 风险/目的：P0，防止页面继续使用组件库默认的黑色 Tooltip 或主题覆盖造成文字不可见。
- 初始路由与状态：CI/CD 发布流详情、环境、日志和账户页面均可通过正常导航访问。
- 测试数据及准备：已有发布流名称、已配置的环境、日志 UID/备注/错误信息、账户状态；全部只读。
- @Browser 操作：悬浮发布流名称（View UI Tooltip）、日志用户名或备注（Poptip）、环境已配置状态（Ant Popover）；另查看任一 Ant Tooltip 入口。比较上下左右箭头，关闭后换页并重新打开。若产品提供主题切换入口，则在亮色/深色下分别重复并恢复原主题。
- 预期结果：所有浮层白底深色文字，箭头与白色表面一致；没有黑色或深灰色独立皮肤；长提示自动换行，短提示不留大块空白；禁用、加载、说明链接和原有交互不变。主题无可操作入口时不通过脚本更改应用状态，仅做主题 CSS 覆盖检查并报告浏览器覆盖缺口。
- 恢复/清理：移出浮层、关闭查看窗口、恢复主题及视口，不触发配置、禁用或删除操作。

### DP-MAIN-01 字段与参数说明

- 风险/目的：P0，确认动态表单和 HTML 说明完整显示。
- 初始路由与状态：实例 / 新增，选择 Kafka 或 Elasticsearch，不提交表单。
- 测试数据及准备：使用后端实际返回的字段说明，例如 Bootstrap Brokers、SASL 认证机制和 Elasticsearch 地址说明。
- @Browser 操作：点击字段旁“说明”按钮，比较较短和较长说明；再次点击或点击外部关闭。打开已有实例的参数配置，悬停参数信息图标；SQL 对象属性说明从隔离 MySQL 实例的 sys / 视图 / version 右键菜单进入 Property；表对象不提供该入口，不从表菜单误判功能缺失。检查属性与值表头跟随当前语言。
- 预期结果：短说明收缩，长说明换行并撑高；原有列表、链接等 HTML 结构保留；浮层没有固定 320px 宽度、240px 高度上限或内部滚动；没有新增复制按钮，表单输入、校验和选项未改变。
- 恢复/清理：离开未提交表单，关闭参数面板。

### DP-BOUNDARY-01 长文本与空内容

- 风险/目的：P1，防止换行、连续字符和空值破坏浮层。
- 初始路由与状态：上述页面已加载对应边界数据。
- 测试数据及准备：已有短、空、长描述、HTML 列表和连续 JSON 文本；缺少时使用 Test Data 的隔离构造方式。
- @Browser 操作：交替悬停短文本和长文本；查看多行、Unicode 和连续无空格文本；滚动页面后重新打开。
- 预期结果：浮层没有上一次内容的宽高残留；换行保留、连续字符可折行、Unicode 不乱码；完整文字不被裁切，内容高度无固定上限；空值不产生仅有边框的空浮层。日志显式设置的最大宽度仍生效，但短文本不强占该宽度。
- 恢复/清理：关闭浮层；只清理本流程创建的隔离临时对象。

### DP-EXTREME-01 响应式尺寸

- 风险/目的：P1，防止浮层超出视口或出现内部横纵滚动。
- 初始路由与状态：选择长团队描述及字段说明浮层所在页面，保持浏览器缩放为 100%。
- 测试数据及准备：长描述和字段说明；记录原视口。
- @Browser 操作：分别在 1440×900、1024×768、390×844 下打开浮层，检查左右边界、完整内容和滚动；表格可横向滚动以定位目标单元格。
- 预期结果：浮层宽度不超过 560px 或视口减 32px；长内容自动换行、撑高且内部没有滚动条；页面自身允许正常滚动。浮层无复制操作区，也没有为已移除按钮保留空白。
- 恢复/清理：恢复原视口。

### DP-LIFECYCLE-01 重进、刷新与连续切换

- 风险/目的：P1，防止共享样式依赖页面访问顺序及浮层残留。
- 初始路由与状态：直接打开任意相关深链接，未先访问工单页。
- 测试数据及准备：已有数据；不更改语言、权限或表单值。
- @Browser 操作：整页刷新，打开描述浮层；移出后快速打开另一条描述，再切换路由并返回。
- 预期结果：首次进入及刷新后样式一致；每次展示对应记录的当前文本；旧浮层不遮挡新页面，无新增相关 Console 错误。
- 恢复/清理：返回原页面。

### DP-PERMISSION-01 只读入口

- 风险/目的：P1，确认显示样式没有扩大修改权限。
- 初始路由与状态：使用已有只读测试账号进入可访问页面。
- 测试数据及准备：只读账号已有可见数据，不调整共享账号授权。
- @Browser 操作：查看描述并尝试选择文字；核对原有编辑或保存入口。
- 预期结果：只读用户可查看授权范围内的描述，不能因浮层得到编辑、复制配置或保存入口；服务端权限行为不变。
- 恢复/清理：恢复原测试会话；无可用只读账号时按 Skip Conditions 报告缺口。

- Failure And Recovery：本改动不增加请求、重试或服务端状态；数据请求错误处理沿用对应页面原流程，不为纯展示样式制造写入失败。
- Repeat And Concurrency / State Consistency：浮层纯只读，无提交并发或持久化状态；连续打开、切页及刷新由 DP-LIFECYCLE-01 覆盖。

## Cleanup

- 关闭说明浮层和未提交的表单，恢复原视口；不修改共享业务记录、审批状态或安全规则。
- 若使用隔离临时对象，按对应功能正常清理并恢复原配置；不得删除非本流程创建的数据。

## Skip Conditions

- 未登录、无页面权限或服务不可用时，依赖该条件的验证标记 BLOCKED，不切换到外部浏览器绕过。
- 未提供隔离安全规则配置时，不执行需要写入才能触发的冲突弹窗；记录该路径仅经源码和构建检查，并使用相同浮层样式的只读入口验证几何行为。
- 旧实例参数面板当前没有可达业务入口或无实际参数时，可在隔离开发预览中挂载真实 ConfigParamsEdit，注册生产使用的 UI 适配器与全局样式，传入只读短说明、HTML 列表、多行及连续长文本；在三种视口验证白色表面、自然尺寸、折行、无内部滚动及复制按钮。该验证只覆盖组件渲染，不冒充生产参数读取或保存流程；不要恢复旧功能或猜路由制造入口。
- 缺少超长边界、空内容或只读账号且不能安全构造时，明确列出未执行场景，不用样式检查冒充真实业务验证。
