# 表格行内操作样式

## Purpose

验证 CI/CD、实例和账号列表的行内操作采用相同绿色文字、字号、间距及悬浮下划线，防止局部按钮皮肤和链接行为不一致。

## Scope

- `/#/cicd` 的详情、发布流拓扑、更多；`/#/datasource` 的测试、编辑、删除；`/#/manager/account` 的授权、修改、删除。
- 共享 `.table-row-actions` 与现有 `DmButton`，不修改操作权限、业务处理、测试连接、授权或删除结果。

## Preconditions

- @Browser 已登录本地环境，三类列表均有可查看数据。
- 使用现有账号权限，不为样式测试扩大权限或修改业务数据。

## Test Data

- 任意已有实例、发布流和账号；账号包含可授权行与授权按钮禁用行（存在时）。
- 不执行测试连接、授权、删除或保存，不构造新的业务数据。

## Suites

### TRA-MAIN-01 统一行内操作

- 风险/目的：P0，防止按钮和原生链接的字体、留白、颜色及 hover 表现不同。
- 初始路由与状态：上述三类列表已加载。
- 操作：分别检查行内操作的计算样式；悬浮操作文字；展开 CI/CD“更多”后点击外部关闭；如需验证路由，仅打开详情或编辑后取消。
- 预期：文字为 14px/400，行高与操作高度为 20px，按钮无额外左右内边距，组内间距为 12px；所有普通行内操作（包括删除）使用全局绿色，悬浮仅在文字下显示 1px 直线下划线（offset 4px），按钮本体 box-shadow 为 none；不得用跟随按钮圆角的内阴影画线；没有单独红色删除、背景块或圆角描边。禁用项灰色且不可触发，原有权限隐藏和 loading 状态保留。
- 清理：关闭菜单和未提交弹窗，返回列表。

### TRA-EXTREME-01 响应式与刷新

- 风险/目的：P1，防止统一间距后操作被裁切或移动端错位。
- 初始路由与状态：列表可见，缩放为 100%。
- 操作：在 1440×900、1024×768、390×844 下检查；使用表格内部横向滚动查看操作列；CI/CD 检查移动端行内操作；刷新并重新进入。
- 预期：操作文字不重叠，按钮基线一致；页面没有新增横向溢出；列表原有内部滚动、移动布局和权限禁用状态保持。
- 清理：恢复视口。

## Cleanup

恢复视口并关闭未提交窗口。无数据创建、修改或删除。

## Skip Conditions

- 无禁用账号或无对应查看权限时，记录缺口，不改变共享账号授权制造状态。
- 不触发真实授权、删除和连接测试；这些业务结果由各自流程验证，本流程仅验证样式与安全的入口操作。
- 纯样式不增加请求和持久状态，无需制造服务故障或并发提交。
