# 在线查询结果缓存容量设置

## Purpose

验证管理员可在偏好设置中查看并修改在线查询结果缓存容量上限，旧的结果缓存有效期不再显示，前后端使用一致的 `MB` 单位、数值边界和 `0` 值语义；防止配置缺失、旧配置回退、非法数值提交、刷新后状态不一致或窄视口遮挡。

## Scope

- 页面与路由：`/#/settings/preferences` 的“数据查询”页签。
- 入口：工作台左侧“设置” → “偏好设置” → “数据查询”。
- 关联接口与状态：系统配置读取与保存接口、`onlineResultCacheCapacityMegaByte` 表单状态、保存与取消按钮状态。
- 关联源码：`frontend/src/views/system/preferenceConfig.js`、`frontend/src/locales/zh.json`、`frontend/src/locales/en.json`、`RootUserConfig`。
- 不覆盖：worker 物理磁盘扫描、批量构造大文件、定时清理任务内部排序和删除 RPC；这些行为由后端验证覆盖。

## Preconditions

- 服务地址与依赖服务：本地 `DmAloneLauncher` 已启动，可访问 `http://127.0.0.1:8222/`。
- 所需账号角色与权限：Chrome 已登录具有系统偏好设置查看和修改权限的管理员账号。
- 稳定初始状态：记录当前 `onlineResultCacheCapacityMegaByte` 值；“偏好设置”页面没有未保存改动。
- 允许的数据写入范围：只允许修改本地环境的该配置，完成后必须恢复原值；不得在生产环境执行写入和边界测试。

## Test Data

| 编号 | 数据说明 | 构造方式 | 唯一标识 | 清理方式 |
|---|---|---|---|---|
| QRC01 | 默认容量 | 新环境不写入该配置，由前后端默认值提供 `1024` | 不适用 | 不写入 |
| QRC02 | 最小值及最小值以上 | 依次输入 `0`、`1` | 不适用 | 恢复测试前数值 |
| QRC03 | 正常值 | 输入 `1024` | 不适用 | 恢复测试前数值 |
| QRC04 | 最大值及最大值以下 | 依次输入 `1048575`、`1048576` | 不适用 | 恢复测试前数值 |
| QRC05 | 上下限外一档 | 依次输入 `-1`、`1048577` | 不适用 | 不保存，取消编辑 |
| QRC06 | 非法输入 | 尝试清空，并输入小数和非数字字符 | 不适用 | 不保存，取消编辑 |

真实边界来自 `preferenceConfig.js` 和 `RootUserConfig`：最小值 `0`、最大值 `1048576`、默认值 `1024`，单位 `MB`。

## Suites

### QRC-SMOKE-01 配置入口、默认值和文案可见

- 风险/目的：P0，确认新配置已由后端提供并由前端正确展示。
- 初始路由与状态：从工作台进入 `/#/settings/preferences`，页面没有未保存改动。
- 测试数据：QRC01。
- 准备方法：使用没有持久化新配置的本地环境，或先通过配置接口确认当前返回值。
- Chrome 操作：
    1. 点击“设置” → “偏好设置” → “数据查询”。
    2. 定位“结果缓存容量上限”。
- 预期结果：
    1. 字段值为 `1024`，单位为 `MB`。
    2. 页面显示“在线查询结果缓存上限大小，超过后按最近访问时间从旧到新清理；0 表示不缓存查询结果。”。
    3. 页面不显示“结果缓存有效期”及其秒数输入框和帮助文案。
    4. 保存和取消按钮在未修改时禁用，配置项没有遮挡或溢出。
- 恢复/清理：无需清理。

### QRC-MAIN-01 保存容量并刷新回显

- 风险/目的：P0，确认配置写入和重新读取一致。
- 初始路由与状态：位于“数据查询”页签，已记录原值。
- 测试数据：QRC03；若原值已经是 `1024`，使用 `1023` 完成本场景。
- 准备方法：确认仅在本地环境操作。
- Chrome 操作：
    1. 修改“结果缓存容量上限”并点击“保存”。
    2. 等待成功提示和按钮退出 loading，再刷新页面。
    3. 重新进入“数据查询”页签。
- 预期结果：
    1. 只发起一次有效保存请求，成功后保存和取消按钮恢复禁用。
    2. 刷新后字段回显已保存值，单位仍为 `MB`，其他数据查询配置不变。
- 恢复/清理：保存测试前记录的原值并刷新确认。

### QRC-BOUNDARY-01 最小值、最大值和外一档

- 风险/目的：P1，确认真实数值边界与 `0` 的特殊语义。
- 初始路由与状态：位于“数据查询”页签，页面没有未保存改动。
- 测试数据：QRC02、QRC04、QRC05、QRC06。
- 准备方法：记录原值。
- Chrome 操作：
    1. 依次输入 `0`、`1`、`1048575`、`1048576`，观察控件和保存按钮状态。
    2. 依次尝试 `-1`、`1048577`、空值、小数和非数字字符。
- 预期结果：
    1. `0` 到 `1048576` 的整数可提交；值为 `0` 时可见“0 表示不保留缓存”和完整帮助文案。
    2. 下限外、上限外、空值、小数和非数字值不能形成有效保存，页面给出既有数字控件校验反馈。
    3. 校验失败不会修改已保存配置。
- 恢复/清理：点击“取消”，确认字段恢复原值。

### QRC-EXTREME-01 常用视口和缩放

- 风险/目的：P1，确认新增配置不会破坏偏好设置的现有表单布局。
- 初始路由与状态：新配置已显示，页面没有未保存改动。
- 测试数据：QRC01。
- 准备方法：记录当前窗口尺寸和浏览器缩放。
- Chrome 操作：分别在 `1440×900`、`1024×768`、`390×844` 以及 `150%` 缩放下查看新字段并滚动到保存按钮。
- 预期结果：字段名称、输入框、`MB` 单位、零值提示和帮助文案可访问；页面可滚动到保存按钮；没有控件相互遮挡或文档级横向溢出。
- 恢复/清理：恢复原窗口尺寸和缩放。

### QRC-REPEAT-01 重复保存

- 风险/目的：P1，防止连续操作造成重复提交或旧响应覆盖新值。
- 初始路由与状态：位于“数据查询”页签，已记录原值。
- 测试数据：QRC03。
- 准备方法：将字段改为与原值不同的合法值。
- Chrome 操作：快速双击“保存”，并在请求期间再次按 Enter；成功后刷新页面。
- 预期结果：请求期间按钮处于 loading 或禁用状态，只产生一次有效提交；刷新后回显最终保存值。
- 恢复/清理：恢复原值。

### QRC-FAILURE-01 保存失败后恢复

- 风险/目的：P1，确认 400、401、403、500、超时或断网不会伪造保存成功。
- 初始路由与状态：位于“数据查询”页签，已记录原值。
- 测试数据：QRC03。
- 准备方法：只在本地环境通过浏览器网络条件或隔离代理注入失败。
- Chrome 操作：修改字段后保存；观察失败状态；恢复网络或接口后重试并刷新。
- 预期结果：失败时出现统一错误提示，按钮退出 loading，页面不提示成功；服务恢复后可以重试，刷新结果与服务端最终值一致。
- 恢复/清理：撤销网络或接口故障，恢复原配置值。

### QRC-LIFECYCLE-01 取消、切页和重新进入

- 风险/目的：P1，确认未保存编辑不会污染后续页面状态。
- 初始路由与状态：位于“数据查询”页签，已记录原值。
- 测试数据：QRC03。
- 准备方法：将字段改为与原值不同的合法值但不保存。
- Chrome 操作：点击“取消”；再次编辑后切换到其他页签或路由，再重新进入“数据查询”。
- 预期结果：取消后立即恢复原值；重新进入后从服务端回显已保存值，不保留未保存输入；页面无持续 loading。
- 恢复/清理：确认字段等于测试前原值。

### QRC-PERMISSION-01 无设置权限账号

- 风险/目的：P0，确认配置读取和保存继续受既有系统设置权限保护。
- 初始路由与状态：使用无系统偏好设置权限的账号登录本地环境。
- 测试数据：无。
- 准备方法：使用已有受限测试账号，不在浏览器中临时创建生产账号。
- Chrome 操作：从工作台查找“偏好设置”入口，并直接访问 `/#/settings/preferences`。
- 预期结果：入口不可见或路由被既有权限逻辑拒绝；账号不能调用有效保存接口。
- 恢复/清理：退出受限账号并恢复管理员测试账号。

### QRC-STATE-01 零值保存后的前后端一致性

- 风险/目的：P0，确认 `0` 在页面和服务端都表示不缓存查询结果。
- 初始路由与状态：本地隔离环境可安全执行只读查询，已记录原配置值。
- 测试数据：QRC02 中的 `0`。
- 准备方法：关闭不相关的查询结果页签，确认测试查询不含敏感数据。
- Chrome 操作：保存 `0` 并刷新确认；进入 `/#/sql` 执行只读查询，检查页面行为；随后恢复容量并重新查询。
- 预期结果：偏好设置刷新后仍显示 `0`；零值下查询不创建可分页或可下载的结果缓存；恢复为正数后新查询重新使用缓存，旧查询状态不会覆盖新配置。
- 恢复/清理：恢复原配置值，关闭测试查询页签。

## Cleanup

1. 将 `onlineResultCacheCapacityMegaByte` 恢复为测试前记录值并刷新确认。
2. 恢复测试账号、网络条件、浏览器缩放和窗口尺寸。
3. 关闭本流程创建的查询结果页签，确认没有遗留网络故障模拟或运行中查询。

## Skip Conditions

- 非本地环境或无法确认环境隔离时，跳过所有配置写入、零值查询和故障注入；只读 Smoke 不能替代这些场景，最终需报告覆盖缺口。
- 没有受限账号时，QRC-PERMISSION-01 可通过代码核对权限链路作为补充，但不得标记为浏览器实测通过。
- 无法安全注入接口错误或断网时，QRC-FAILURE-01 跳过并保留恢复路径覆盖缺口。
- 无法安全构造足以触发容量淘汰的查询结果时，只验证配置契约和后端清理代码路径，不把真实 LRU 删除标记为实测通过。
