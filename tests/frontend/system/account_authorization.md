# 账号资源授权

## Purpose

验证账号资源授权页在常规桌面、标准 MacBook 和浏览器高缩放下仍能完整选择资源、配置授权时间并进入预览，防止资源树、权限树和选项面板相互挤压或出现难以操作的横向页面滚动。

## Scope

- 页面：账号列表、单账号资源授权、批量授权的权限选择步骤。
- 路由：`/#/manager/account`、`/#/system/account/authdm/:uid`、`/#/manager/account/batch_authorization/permissions`。
- 状态：查看、编辑、授权预览、批量授权与批量移除。
- 不覆盖：后端权限计算正确性、跨租户隔离、真实生产账号授权提交和数据源权限模型内部实现。

## Preconditions

- 本地 `DmAloneLauncher` 已启动，访问地址为 `http://127.0.0.1:8222/`。
- Chrome 已登录具备账号查看与 `RDP_AUTH_MANAGE` 权限的测试管理员。
- 至少存在一个可编辑的测试账号，以及包含实例、Schema 和表节点的测试数据源。
- 布局场景只浏览和选择资源，不点击最终“保存”；需要提交时只能使用隔离测试账号并在结束后恢复权限。

## Test Data

- 选择一个显示名称带唯一标识 `codex_auth_<时间戳>` 的测试账号；不要依赖固定 UID。
- 资源树至少包含一个短名称数据源、一个超长中英文名称数据源、三层以上 Schema/表路径和一个空节点分支。
- 时间范围覆盖永久、一天、一周、一月、一年和自定义；自定义时间使用当前时间之后的有效区间。
- 批量场景使用两个可恢复权限的测试账号，预览后退出，不提交到共享环境。

## Suites

### AA-SMOKE-01 页面与资源选择

- 风险/目的：P0，确认授权页核心区域可达且资源选择仍可操作。
- 初始路由与状态：从账号列表定位测试账号并点击授权。
- 测试数据：单账号与多层资源树。
- 准备方法：记录测试账号唯一名称，通过可见列表入口进入授权页。
- 操作步骤：展开实例、Schema 和表节点；在左侧搜索框检索长名称节点；点击资源后切换实例、Catalog、Schema、表权限页签。
- 预期结果：面包屑显示“账号 / 授权”；左侧资源树、当前资源摘要、权限页签和选项区均可见；资源树内部可独立纵向滚动，长名称省略但不撑破页面；点击资源后当前资源路径和权限树同步更新；禁用页签不可点击，可用页签选中态清晰。
- 恢复/清理：清空搜索条件并返回账号列表。

### AA-MAIN-01 时间与预览

- 风险/目的：P0，确认响应式重排不破坏授权表单和预览状态。
- 初始路由与状态：单账号授权编辑页已加载。
- 测试数据：一个可勾选权限的测试资源。
- 准备方法：选择测试资源并勾选一个非破坏性权限。
- 操作步骤：依次选择永久、一天、一周、一月、一年和自定义；填写合法自定义时间；切换“全部资源”开关后立即恢复原值；点击“授权预览”，再点击“上一步”。
- 预期结果：时间按钮均保持完整可点，选中态与 `aria-pressed` 一致；自定义开始和结束时间纵向排列且不重叠；全部资源开关及说明完整可读；预览按钮始终位于页面内页脚；进入预览后资源和时间与编辑态一致，返回上一步后选择不丢失；不产生最终保存请求。
- 恢复/清理：恢复全部资源开关原值，退出授权页。

### AA-EXTREME-01 MacBook 与高缩放布局

- 风险/目的：P0，防止高缩放时三列固定最小宽度导致页面横向溢出和操作面板不可达。
- 初始路由与状态：授权编辑页已加载并选中一个包含权限树的资源。
- 测试数据：长数据源名称、深层资源路径和完整六档时间范围。
- 准备方法：保持选项区可见，不提交变更。
- 操作步骤：依次使用 1512×982、1440×900、1209×786、1152×720、1008×655、960×600 和 390×844 有效视口；在 1280px、1024px、768px 断点两侧复核资源树、权限树、选项区和页脚。
- 预期结果：宽屏保持资源树、权限树、选项三列；中等有效视口保持资源树在左，权限树在右，选项区移动到权限树下方并使用两列选项，不挤压权限内容；1024px 以下资源树和权限配置改为上下布局，选项区在窄屏改为单列；拖拽分隔条只在宽屏出现；页面没有横向滚动条，所有资源节点、页签、时间按钮、开关、返回和预览按钮均能通过鼠标或触控板到达；纵向滚动只发生在授权内容区，页脚不遮挡内容。
- 恢复/清理：恢复原视口和 100% 缩放。

### AA-LIFECYCLE-01 刷新与返回

- 风险/目的：P1，确认重排状态下刷新和路由返回不会出现空白布局或尺寸残留。
- 初始路由与状态：在中等有效视口打开授权编辑页。
- 测试数据：测试账号和已选资源。
- 准备方法：从账号列表进入页面并切换一次权限页签。
- 操作步骤：刷新页面；调整到宽屏再缩回中等视口；点击返回账号列表；使用浏览器后退重新进入。
- 预期结果：刷新后页面重新加载且无空白列；每次尺寸变化都按当前断点重排，不保留上一个宽度的固定列宽；返回和后退路由正确，账号列表筛选区和表格仍可操作。
- 恢复/清理：返回账号列表。

### AA-PERMISSION-01 只读与无权限

- 风险/目的：P0，防止响应式样式误暴露授权操作。
- 初始路由与状态：分别使用只读账号和无账号管理权限的账号访问。
- 测试数据：同一个测试账号。
- 准备方法：管理员为测试登录账号配置最小权限，结束后恢复。
- 操作步骤：只读账号查看授权页；无权限账号尝试通过可见导航进入账号管理。
- 预期结果：只读态不可修改资源、时间和全部资源开关；无权限账号不显示管理入口或被统一权限路由拦截；响应式重排不改变权限判断和按钮可见性。
- 恢复/清理：恢复测试登录账号权限。

## Cleanup

- 不在共享环境提交授权；若隔离环境完成了保存，按测试前记录恢复测试账号原权限。
- 恢复 Chrome 100% 缩放、原窗口尺寸和账号列表筛选条件。
- 删除只为本流程创建的测试账号与测试资源时，必须确认其不被其他流程引用。

## Skip Conditions

- 没有 `RDP_AUTH_MANAGE` 权限时，可执行只读布局和路由场景；编辑、预览和提交标记为 SKIP。
- 没有可恢复的隔离测试账号时，不执行最终保存；预览验证不能替代服务端授权提交验证。
- 资源树没有 Catalog 或多层 Schema 时，对应页签和深层树场景可 SKIP，但必须保留长名称与多视口布局检查。
- 浏览器无法设置指定有效视口时，可用等效浏览器缩放和窗口大小替代，并记录未覆盖断点。
