# OpenSearch 入口与 REST 工作台

## Purpose

验证 OpenSearch 以独立产品身份接入数据源入口、连接表单和 REST 工作台；复用 ES 的编辑交互时，连接配置、服务端产品能力、结果和权限仍绑定各自会话。

本流程供开发完成后的统一浏览器验收使用，不代表已通过。由维护者启动应用并在内置浏览器登录后执行验收；不为验收自动启动应用或执行数据库迁移。

## Scope

- 路由：`/#/datasource`、`/#/datasource/add?dsType=OpenSearch`、`/#/datasource/add?mode=edit&dsId=<ID>&dsType=OpenSearch`、`/#/sql`。
- 入口：新增类型选择、实例列表、工作台数据源树、查询页签、命令模板、结果区。
- 前端 `es` 仅是共享编辑器语言 ID。语言服务沿用当前 `sessionId` 和资源层级，不能把 OpenSearch 实例改成 ElasticSearch，不能覆盖后端真实产品和版本。
- 通用流程引用：[实例国际化](instance_i18n.md)、[测试连接](test_connection.md)、[SQL 语句选择](../sql/sql_statement_selection.md)、[结果表格](../sql/query_result_grid.md)。本文件仅补充 OpenSearch 的差异与跨产品回归。
- 服务端语义引用：[REST DSL](../../datasource/opensearch/rest-dsl-integration.cn.md)、[元数据与执行](../../datasource/opensearch/metadata-execution.cn.md)、[分页与导出](../../datasource/opensearch/pagination-export.cn.md)、[权限与脱敏](../../datasource/opensearch/security-integration.cn.md)。不重复维护完整数据库能力矩阵。

## Preconditions

- 由维护者启动已加载最新 Web 和 `ds-opensearch` 插件的 CloudDM，确认数据库版本与最终开发版本匹配。
- 使用隔离环境，准备有实例新增、修改、查询权限的账号，以及只读/受限账号。证书、密码和真实连接信息不写入仓库或流程截图。
- 准备 OpenSearch 2.x、3.x 的独立测试实例，以及 ES、MySQL 对照实例；实际覆盖版本记录到 OpenSearch 能力矩阵，不以一个版本替代全部版本。
- OpenSearch 数据库账号具有长期集成流程所要求的元数据权限；3.3+ 查询还需要读取系统 Search Pipeline 配置。插件驱动已准备或可从配置的来源下载。
- 查看当前实例所属环境、权限和脱敏策略后再测试；只操作本次唯一前缀的测试索引。

## Test Data

将 `<runid>` 替换为本次唯一的小写标识，索引采用 `cdm_os_ui_<runid>`；测试实例名称采用同一前缀。

| 数据 | 准备方式 | 用途 |
| --- | --- | --- |
| 连接 | 维护者提供 HTTP/HTTPS 单地址及逗号分隔的双地址、有效账号和 CA | 新增、重开、编辑和测试连接；不要在 URI 中包含凭证 |
| 索引 | 由维护者通过数据库客户端建立精确索引，字段 `name: keyword`、`seq: integer`，写入三条可辨认文档并刷新 | 树、字段、Mapping、Settings、模板和结果 |
| 文档 | `1: {"name":"中文;GET /other","seq":1}`、`2: {"name":"😀","seq":2}`、`3: {"name":"third","seq":3}` | Unicode、分号、字符串中的请求头、结果顺序 |
| 空结果 | 对上述索引使用 `match_none` | 空态与执行计数 |
| 大结果 | 复用分页与导出流程的隔离数据准备方式 | 超过自动分页阈值的展示、导出、取消；不在浏览器中手工批量造数据 |

多请求示例（先替换索引名）：

```http
# comment; GET /not-a-request
GET /cdm_os_ui_<runid>/_search
{"query":{"term":{"name":"中文;GET /other"}}}

GET /cdm_os_ui_<runid>/_count
```

索引准备绕过 CloudDM 创建路径只是为了隔离前端验收；首期命中索引模板就拒绝创建的产品限制仍保留，其验证按安全集成流程执行。

## Suites

### OS-UI-SMOKE-01 名称、图标与分组

- 风险/目的：P0，防止产品无法发现、图标空白或被识别成 ES。
- 初始状态：`/#/datasource`，管理员已登录，插件已加载。
- 操作：进入新增页，按名称搜索 OpenSearch，选择类型；返回列表后进入 `/#/sql`，定位已配置的 OpenSearch 实例并打开查询窗口。
- 预期：类型选择中 OpenSearch 出现在后端下发的非关系型分组；新增页、实例列表、树和查询页签使用 OpenSearch 名称与独立图标。ES 入口继续保留。无空图标、重复卡片、错误产品名或持续加载。
- 清理：清空筛选，关闭本次新开的查询窗口。

### OS-UI-MAIN-01 新增、保存重开与修改

- 风险/目的：P0，防止多地址被拼上额外端口、配置丢失或凭证被回填占位符覆盖。
- 初始状态：新增页选择 OpenSearch，使用本次专用实例名称。
- 操作：填写双地址和账号，按协议配置 SSL/CA，设置可辨认的合法连接池及超时配置，测试后保存；返回列表，重新进入修改页；修改一个超时值后保存并再次打开。个人数据源入口可用时用同一隔离实例覆盖一次新增。
- 预期：地址为完整 URI 列表，未增加独立端口输入或在整串 URI 末尾追加端口；保存重开后地址、认证方式、证书配置状态和选项一致。未重新输入密码/证书时不会把空值或配置占位符作为新凭证提交。测试连接终态和按钮恢复遵循通用流程。
- 清理：删除本次新增的 CloudDM 测试实例，已有实例不修改。

### OS-UI-MAIN-02 REST 编辑、当前请求与模板

- 风险/目的：P0，防止误选整个缓冲区或把 JSON 当作 SQL 格式化。
- 初始状态：`/#/sql` 的 OpenSearch 查询页签，测试索引可见。
- 操作：双击索引生成快捷查询；打开该索引的命令模板并插入一条；再输入多请求示例，将光标依次放在请求头、JSON 内和第二条请求内，等待拆句完成后执行；触发路径、参数和 JSON 字段补全，格式化整个文档，再撤销；手动选择第二条完整请求执行。
- 预期：生成真实索引的 REST 请求，无 `%%TABLE%%` 等残留；方法、路径、JSON 字段/字符串/数字与注释使用 REST 高亮。当前请求框包含对应请求的完整正文，每次只执行目标请求；字符串中的分号和 `GET` 不产生额外请求。补全和校验依据当前产品及版本；格式化保留字符串/Unicode/数值语义，撤销能恢复原文。语法格式化成功不表示请求通过能力校验。
- 清理：清空测试文本与结果，保留其他用户窗口。

### OS-UI-MAIN-03 中英文表单与错误提示

- 风险/目的：P1，防止动态插件字段或编辑器失败提示回退成硬编码中文。
- 初始状态：`/#/datasource/add?dsType=OpenSearch`，页面语言为中文。
- 操作：按实例国际化流程切换 English，重新打开新增/修改页，检查地址说明、认证、SSL、连接池和超时项；再进入工作台检查语言服务失败提示。切回中文复查。
- 预期：通用文案与插件动态字段跟随当前语言，OpenSearch 品牌名称保持原名；客户端未收到服务端错误正文时，语言服务失败提示也使用当前语言。页面不暴露原始国际化 key。
- 清理：恢复原语言，不保存本场景的表单输入。

### OS-UI-BOUNDARY-01 不完整请求、空白和语言服务失效

- 风险/目的：P0，防止无可靠拆句结果时降级为 SQL 分号切分并执行错误范围。
- 初始状态：OpenSearch 查询窗口已打开，使用上述多请求示例。
- 操作：依次测试空文档、纯注释、正文缺少右括号；恢复有效文本后，在前一请求未返回时继续编辑；断开浏览器网络，修改文本后尝试“执行当前请求”，随后恢复网络并等待新拆句结果。
- 预期：无当前有效范围时不沿用旧范围或把整段 REST 当作一条 SQL；执行入口提示无可执行请求或保持不可用，不自动发送查询。恢复后能重新选中有效请求。手动完整选择的执行仍由后端校验，不绕过权限和语法检查。
- 清理：恢复网络、有效文本和初始选择状态。

### OS-UI-EXTREME-01 展示与视口

- 风险/目的：P1，防止图标缩放、长地址、JSON 或空结果破坏已有布局。
- 初始状态：新增表单与 OpenSearch 查询窗口，使用长但合法的双地址、Unicode 文档和空结果查询。
- 操作：在 1440×900、1024×768、390×844 和 150% 缩放下检查类型选择与表单；工作台窄屏按既有流程收起侧栏，执行有数据/空结果查询，查看文档详情和结果区滚动。
- 预期：独立图标保持比例、未挤压名称；表单可滚动到操作按钮，地址不覆盖标签；JSON 内容完整可查看、Unicode 正确，空结果不遗留上一查询的数据。工作台维持现有桌面优先布局，窄屏不新增控件遮挡。
- 清理：恢复窗口尺寸、缩放和主题，关闭测试结果。

### OS-UI-CONCURRENCY-01 多产品页签与迟到响应

- 风险/目的：P0，共享 `es` 高亮注册不能造成补全或格式化串会话。
- 初始状态：同时打开 ES、OpenSearch 和 MySQL 查询窗口。
- 操作：在 ES/OpenSearch 页签交替输入并触发补全；按 DSL 集成流程对照产品专用参数；格式化请求发出后立即修改文本或关闭窗口；快速切换窗口再执行查询。MySQL 运行通用语句选择流程中的分号回退用例。
- 预期：补全、校验和执行请求绑定各自实例，OpenSearch 不接受 ES 专属能力；关闭或编辑后的旧格式化响应不覆盖新文本；MySQL SQL 高亮和分号回退不变，ES REST 行为不回归。
- 清理：关闭本次窗口，不保存混合产品的临时文本。

### OS-UI-RECOVERY-01 连接和请求失败

- 风险/目的：P0，防止认证失败、权限失败和取消后状态滞留或自动重放写入。
- 初始状态：专用新增表单或查询窗口，准备有效/无效凭证和可取消的隔离查询。
- 操作：执行错误密码、错误 CA、不可达地址的测试连接；修正配置重试。查询中断网或取消，然后恢复连接执行只读查询；按元数据与执行流程构造冲突/部分失败。
- 预期：错误可见、加载结束、按钮恢复，修正后可重试；查询失败/取消不伪装成功，部分失败保留实际执行信息，不自动重放未知结果的写请求。取消按钮不会永久占用会话。
- 清理：恢复网络及有效配置，终止仍在运行的隔离查询。

### OS-UI-LIFECYCLE-01 页面刷新、切换类型与重开

- 风险/目的：P1，防止缓存的编辑器语言或连接配置污染另一数据源。
- 初始状态：新增页先选择 MySQL；另有已保存 OpenSearch 实例。
- 操作：填入端口后切换到 OpenSearch，再切回 ES/MySQL；取消新增。刷新已保存实例页面，重新进入工作台；关闭并重开 OpenSearch 查询页签。
- 预期：按当前类型重新加载表单，不沿用上一产品的端口或 SSL 输入；OpenSearch 地址保存仍完整。重新进入后保持独立身份、REST 高亮与补全，已保存配置与服务端一致。
- 清理：取消未保存表单，关闭本次查询页签。

### OS-UI-PERMISSION-01 权限、只读与脱敏出口

- 风险/目的：P0，入口可见与语法提示不能代替执行授权。
- 初始状态：`/#/datasource` 和 `/#/sql`，按安全集成流程切换管理、只读、受限/脱敏账号。
- 操作：检查新增/修改入口和数据源只读配置，保存后重开工作台，尝试写请求、受限索引访问和受限字段查询；查看结果详情、复制和导出。分别打开 Elasticsearch、OpenSearch、Kafka、Etcd 查询窗口，刷新并关闭重开，检查工具栏。验证账号过期后重新登录的页面恢复。
- 预期：页面/按钮遵守平台权限；数据库拒绝也明确呈现。四类数据源工作台均不显示会话“只读”切换按钮；数据源配置的只读限制仍生效，写入被拒绝、读取可用。脱敏在表格、详情、复制及导出一致；不可靠脱敏请求明确拒绝。无权限的数据不因旧窗口或缓存继续展示为本次查询结果。
- 清理：恢复原账号，移除本次专用权限与规则，不修改共享策略。

### OS-UI-STATE-01 结果、计数与导出一致性

- 风险/目的：P0，防止 REST 已接通但结果缓存、页签或执行计数错误。
- 初始状态：OpenSearch 查询窗口，使用三条文档、空结果及分页流程的隔离数据。
- 操作：执行普通查询、聚合、`_count`、文档读取及已约定的写操作；切换结果页签和文档详情；按分页与导出流程查询超过自动分页阈值的数据，导出并核对标识与计数；关闭结果页签再执行一次查询。
- 预期：空结果、聚合 JSON、写入状态与影响条数按真实返回展示；REST 执行文本完整，不套用 SQL 关键字着色。展示和导出内容/脱敏一致，无重复遗漏；失败不能留下成功的等待页签或混入旧结果。关闭和取消按分页流程验证游标清理。
- 清理：关闭结果与查询窗口，删除下载文件，按对应集成流程清理隔离数据。

### OS-UI-STATE-02 跨页导出与自定义 routing

- 风险/目的：P0，防止只导出当前展示页、丢失大整数或拒绝合法的同 ID 文档。
- 初始状态：OpenSearch 3.3+ 查询窗口，按分页集成流程准备两个双分片专用索引，分别使用普通 ID 和落在不同分片的自定义 routing；平台行数上限至少为 3000。
- 数据与准备：每个索引至少 2505 条，正文包含唯一递增 `seq`、重复 `rank`、中文/emoji 和 long 值 `9007199254740993`。routing 索引按 PAGE-19 准备同页和第 1000/1001 条的相同 `_id`；不能用无 `_routing` 字段的模拟响应替代真实响应。
- 操作：分别执行 `size:3000`、按 `seq` 升序的查询；查看首尾展示页。点击“导出”，选择“全部导出”和 Json，点击“确认导出”；等待进度完成，再点击结果工具栏“下载”，在“下载文件”弹窗确认文件名并点击“下载”。解析文件，逐条对照基线的 `seq`、正文和排序值。
- 预期：2505 条均在同一结果集中，最后展示页不遗漏尾行；原生 hit 含 `_routing` 时，普通分页不能因此报无法安全合并。文件包含全部行，`seq` 顺序及集合完整，中文/emoji、大整数精度保持，自动添加的 PIT 排序值不泄漏。脱敏场景另按安全集成流程验证，不能因普通查询通过而放宽脱敏白名单。
- 清理：删除本场景索引和下载文件，核对专用索引游标数回到基线。

### OS-UI-RECOVERY-02 取消时序

- 风险/目的：P0，避免按钮瞬时状态掩盖服务端未应用取消请求。
- 初始状态：已有成功查询的 OpenSearch 会话；使用本次专用索引及文档，不修改共享权限。
- 操作：执行跨页查询，确认本次请求已开始接收数据，再点击“中断”；检查执行信息，并在终态后运行短查询。
- 预期：取消命中在途请求后不再输出后续页，失败/取消终态明确，下一次查询可执行，已知游标清理。若提示“没有正在进行的查询”后原查询仍开始执行，必须记录未覆盖在途取消，不能记为取消成功。
- 清理：结束查询并删除专用测试文档。

### OS-UI-BOUNDARY-02 聚合完整性标志

- 风险/目的：P1，区分真正的空聚合与服务端声明的提前终止，避免误报完整成功。
- 初始状态：专用索引有可核对的桶计数，账号可执行聚合。
- 操作：分别执行 `size:0` 和 `size:1` 的同一聚合；若前者报部分结果，使用外部数据库客户端对同一索引和正文核对原生 `timed_out`、`terminated_early` 和 `_shards.failed`，不省略响应标志。
- 预期：正常聚合按名称和值展示，桶计数与基线一致。原生响应含 `terminated_early:true` 时遵循现有拒绝规则，不能只根据 HTTP 200 或已返回桶就断言完整成功；需要支持该版本优化行为时另行确认语义。
- 清理：关闭测试结果，不修改集群搜索设置来绕过完整性校验。

## Cleanup

- 恢复网络、账号、主题、语言、视口和缩放；关闭本次新增的窗口，不覆盖已有查询。
- 删除本次唯一前缀的 CloudDM 实例与测试索引、证书和权限，确认没有仍在运行的请求或游标；不要删除复用的环境/实例。
- 保留本流程，验收证据回填已有能力矩阵，不生成按日期命名的重复流程文档，不保存凭证或敏感返回数据。

## Skip Conditions

- 应用、插件或数据库版本尚未准备：相关用例待验收，不启动迁移来绕过前置条件。
- 无某版本、ES/MySQL 对照实例、权限账号或隔离故障环境：明确记为未覆盖，不能以其他版本或管理员成功替代。
- 无安全的大数据/取消测试准备：对应极限场景跳过，不对共享业务数据注入故障。
- 自动化单测和 Web 构建仅补充证据，不能替代本流程的浏览器与真实连接验证。
