# 数据源默认驱动选择

## Purpose

验证新增数据源时，前端只依据后端 `driverFamilies[].defaultVersion` 选择默认驱动家族和版本，防止重新引入前端内置驱动清单或误选版本列表首项。

## Scope

- 页面与路由：实例列表 `/#/datasource`、新增数据源 `/#/datasource/add?dsType=<类型>`。
- 入口：实例列表“新增”按钮和数据源类型选择弹窗。
- 关联接口与状态：全局设置中的 `dsSettingDef.<类型>.driverFamilies`；驱动状态检查接口不属于默认选择断言。
- 关联源码：`frontend/src/components/form/DriverSelection/DriverSelectionField.vue`、后端 `DsDriverFamily` 与各插件 `drivers.xml`。
- 不覆盖：驱动下载、连接测试、保存数据源和 Sidecar 驱动文件完整性。

## Preconditions

- 本地服务可通过 `http://localhost:8222` 访问，Console 和至少一个 Worker 正常运行。
- 使用已登录且拥有实例查看、新增权限的测试账号。
- 后端加载的目标插件描述符至少有两个驱动版本，其中一个版本配置 `default="true"`。
- 本流程不提交新增数据源，不产生业务数据。

## Test Data

| 编号  | 数据说明       | 构造方式                                                        | 唯一标识 | 清理方式 |
|-----|------------|-------------------------------------------------------------|------|------|
| D01 | MySQL 默认驱动 | 使用仓库 MySQL `drivers.xml`；默认版本为 8.4.0，版本列表还包含 9.6.0 等版本 | 不适用  | 无需清理 |
| D02 | 无默认版本的类型   | 使用未配置 `default="true"` 的驱动家族，或在隔离测试分支临时构造描述符              | 不适用  | 恢复描述符 |

## Suites

### DRIVER-SMOKE-01 默认驱动可见

- 风险/目的：P0，确认新增页面可达并展示驱动家族、版本。
- 初始路由与状态：已登录，位于 `/#/datasource`。
- 测试数据：D01。
- 准备方法：确认后端全局设置已加载 MySQL 驱动列表。
- Chrome 操作：
    1. 点击“新增”，在“选择数据源类型”弹窗选择“MySQL”并确认。
    2. 等待进入 `/#/datasource/add?dsType=MySQL`。
- 预期结果：
    1. 页面显示“驱动”和“版本”控件，无加载错误。
    2. 驱动为 `MySQL Connector/J`，版本为 `8.4.0`。
    3. Console 不出现与驱动默认选择相关的错误。
- 恢复/清理：不填写表单，不点击“新增数据源”，离开页面。

### DRIVER-MAIN-01 后端默认版本优先于列表首项

- 风险/目的：P0，防止前端按版本排序后的首项选择 9.6.0。
- 初始路由与状态：进入 MySQL 新增页面，表单尚未编辑。
- 测试数据：D01。
- 准备方法：确认接口返回的 MySQL `versions` 同时包含 `9.6.0` 和 `8.4.0`，`defaultVersion` 为 `8.4.0`。
- Chrome 操作：
    1. 展开版本下拉框，确认两个版本均可选。
    2. 不作选择并关闭下拉框。
- 预期结果：初始选中值保持 `8.4.0`，而不是版本列表首项 `9.6.0`。
- 恢复/清理：离开页面。

### DRIVER-BOUNDARY-01 无默认值时回退首项

- 风险/目的：P1，兼容尚未声明默认版本的插件。
- 初始路由与状态：目标类型的 `driverFamilies` 不含 `defaultVersion`。
- 测试数据：D02。
- 准备方法：仅在隔离测试环境加载该描述符。
- Chrome 操作：进入目标类型的新增页面。
- 预期结果：选择第一个驱动家族及其 `versions[0]`，页面不报错。
- 恢复/清理：恢复描述符并重启相关服务。

### DRIVER-BOUNDARY-02 多家族默认选择

- 风险/目的：P1，确认默认版本同时决定默认驱动家族。
- 初始路由与状态：目标类型包含多个驱动家族，只有一个家族提供有效 `defaultVersion`。
- 测试数据：D03。
- 准备方法：确认后端响应中的默认版本属于对应家族的 `versions`。
- Chrome 操作：进入该类型的新增页面。
- 预期结果：默认选中包含 `defaultVersion` 的家族，并选中该版本；切换到其他家族时按该家族默认版本或首项选择。
- 恢复/清理：离开页面。

### DRIVER-LIFECYCLE-01 重新进入保持后端默认

- 风险/目的：P1，防止路由切换后残留上一次表单的驱动选择。
- 初始路由与状态：完成 DRIVER-SMOKE-01，但未提交表单。
- 测试数据：D01。
- 准备方法：无。
- Chrome 操作：返回实例列表，再次选择 MySQL 进入新增页面。
- 预期结果：新表单重新选择 `MySQL Connector/J / 8.4.0`。
- 恢复/清理：离开页面。

### DRIVER-PERMISSION-01 无新增权限

- 风险/目的：P0，确认默认驱动字段不会绕过既有实例新增权限。
- 初始路由与状态：使用没有实例新增权限的账号。
- 测试数据：无。
- 准备方法：管理员在隔离环境准备只读账号。
- Chrome 操作：访问实例列表并尝试打开新增路由。
- 预期结果：“新增”入口不可见或路由被拒绝；不能进入可提交的数据源表单。
- 恢复/清理：恢复测试账号权限。

### DRIVER-STATE-01 前后端默认值一致

- 风险/目的：P0，确认页面展示与当前后端契约一致。
- 初始路由与状态：新增页面已打开。
- 测试数据：D01。
- 准备方法：读取非敏感全局设置响应中的目标 `driverFamilies`。
- Chrome 操作：对照响应中的 `defaultVersion` 与页面初始版本，然后刷新页面。
- 预期结果：刷新前后页面初始版本都等于后端 `defaultVersion`；前端资源中不存在独立内置驱动 JSON 清单。
- 恢复/清理：关闭复测标签页。

Repeat And Concurrency 不适用：默认选择是同步纯本地状态初始化，没有提交、轮询或并发写入。Failure And Recovery 仅在全局设置请求失败时由页面统一错误处理覆盖，本流程不重复定义。Extreme 不适用：改动不涉及列表规模、布局或响应式行为。

## Cleanup

1. 不提交新增数据源表单。
2. 恢复为边界场景临时修改的描述符和测试账号权限。
3. 关闭复测标签页，确认没有驱动下载任务。

## Skip Conditions

- 本地服务不可用、Chrome 未登录或缺少实例新增权限时，浏览器场景标记 SKIP；后端解析测试和前端构建不能替代页面默认值验证。
- 无法安全加载临时描述符时，DRIVER-BOUNDARY-01 标记 SKIP，并以解析单测覆盖无默认值回退契约。
- 没有只读测试账号时，DRIVER-PERMISSION-01 标记 SKIP，并明确保留权限覆盖缺口。
