# HANA 页面能力与国际化

## Purpose

验证 HANA 能力声明、页面入口、实际操作和中英文文案一致，覆盖格式化调用、对象脚本菜单与不支持项反馈。覆盖默认开放后的入口与已有配置回归，不能用插件构建或离线探针替代页面验收。

## Scope

- 页面：数据源配置、SQL 工作台、对象树、工单详情。
- 路由：`/#/datasource`、`/#/datasource/add?dsType=Hana`、`/#/sql`、`/#/ticket/:id`。
- 格式化：HANA SQL/SQLScript，以及 MySQL、Oracle 对照；同时核对格式化能力为 No 的数据源。
- 连接、结构编辑、数据编辑、权限与脱敏复用现有流程，不在本文重复维护。
- 包含默认入口新增、已有连接配置和重启恢复；不包含 Cloud 认证或第 12 步公共事务/重试专项。

## Preconditions

- 代理执行时使用 @Browser 内置浏览器；也可由用户按同一流程手动执行，结果记录执行方式。CloudDM 测试服务已启动并加载匹配的 Web、平台和 HANA 插件。
- 已登录具备测试数据源权限的账号。需要登录时由用户在浏览器完成，不读取 Cookie、Token 或 local storage。
- HANA 插件为 `display=true`，使用正常新增入口；准备一个更新前已保存的 HANA 测试连接用于配置回归。驱动按在线准备或完整缓存离线预置，不假定发布包内置 ngdbc。
- Express tenant、普通账号和隔离 schema 依据 [HANA 环境说明](../../datasource/hana/README.md) 准备。
- MySQL、Oracle 对照连接可用；记录各类型真实返回的 `tab.support.format.conf`。

## Test Data

- HANA：复用 [SQLScript 拆句样本](../../datasource/hana/sql/06-split.sql)、[结构样本](../../datasource/hana/sql/10-structure.sql)。只进行格式化时不执行样本 SQL。
- 额外格式化输入：

```sql
DO BEGIN DECLARE N INTEGER = 0; IF :N = 1 THEN SELECT '中文;''值' AS "A;" FROM DUMMY; ELSEIF :N = 2 THEN N = 3; ELSE N = 2; END IF; END;
```

- MySQL：`select a,b from t where a=1;`；另加反引号列名、转义字符串、行注释样本。
- Oracle：`select q'[a;''b]', "Case" from dual where x=:x;`。
- 错误输入：未闭合引号、未闭合块注释、缺少 END 的 SQLScript；准备属性限制/只读列/无法转换的目标类型等受限操作样本。
- 七类脚本对象：表、视图、过程、函数、触发器、序列、同义词；只在隔离 schema 创建。

## Suites

### HANA-UI-00 默认入口与已有配置

1. 使用具备新增数据源权限的账号进入 `/#/datasource`，点击新增，确认列表可见 HANA 并进入配置表单；不要用直达路由代替此断言。
2. 在线环境准备所选驱动；离线环境按环境说明预置完整缓存，在实际负责连接的进程验证加载成功。
3. 填写 tenant SQL 端口、账号和 schema，测试连接并保存；从列表重新打开，核对驱动、租户/schema、TLS/SSH 字段未丢失。
4. 打开 SQL 工作台，在已授权的隔离表执行查询，核对对象树、列与结果；后续能力使用下列既有流程验收。
5. 打开更新前保存的 HANA 连接，核对配置并连接。按测试部署的正常流程重启应用/执行节点，刷新页面后再打开新增连接和旧连接，核对配置、插件与驱动仍可用；不要求 JDBC 会话参数跨重启保留。
6. 以受限平台账号核对连接、对象和操作可见性仍遵循已有权限，不因产品入口开放获得额外权限。

预期：正常新增列表可选 HANA；已有配置无须迁移即可重新加载，重启后可以重新建立连接。缺少旧配置、离线或分布式部署条件时，对应子项单独保留 NOT RUN，不以新增直连成功替代。

### HANA-UI-01 配置与会话能力

1. 从正常新增入口选择 HANA，或打开已有 HANA 配置，分别切换中文和英文。
2. 核对 tenant 与 schema 描述、实际 SQL 端口提示、JDBC 地址、SSH/TLS、证书主机名和超时单位。
3. 连接后打开 SQL 工作台，核对 tenant 不允许在连接内切换、schema 可以切换，隔离级别不包含 READ UNCOMMITTED。
4. 核对执行计划、取消、格式化等按钮与服务端能力声明一致。

预期：无裸国际化 key、无英文界面夹带中文提示；不把 SYSTEMDB 端口当成 tenant 端口。连接/TLS 的实际验证复用环境说明，不以表单可见推定通过。

### HANA-UI-02 格式化与撤销

1. 打开 HANA SQL 编辑器，粘贴单行 SELECT/JOIN/CTE/DML/DDL 和上面的 SQLScript 输入，点击“格式化”。
2. 核对 SQL 子句、字段列表、表定义和 BEGIN/IF/ELSEIF/ELSE/WHILE/FOR/LOOP/CASE 的层次缩进；小数精度与函数参数不被拆成表定义。
3. 再点一次格式化，文本应完全一致且不新增无意义撤销记录；撤销一次恢复格式化前全文，重做恢复格式化结果。
4. 在字符串或注释内部选择一段文字，再格式化；操作仍作用于全文，不截取局部字面量。
5. 对含转义引号、Unicode、注释内分号、嵌套块注释、多行字符串的输入，核对这些内容原样保留。
6. 粘贴错误输入后点击格式化，核对中英文错误提示和编辑器原文。

预期：格式化仅改变排版，不执行 SQL；不完整或不能安全格式化的输入保留原文并提示。原生词法 token、对象名、字符串和注释内容不变。

### HANA-UI-03 能力一致性与其他方言

1. 分别切换 HANA、MySQL、Oracle 的 SQL tab，核对按钮按当前 tab 的 `support.format.conf` 显示；Allow/Hint 可用，No 或尚未加载不显示。
2. 对各自样本点击格式化，核对都有实际排版结果；MySQL 反引号/转义字符串和 Oracle q 字符串、绑定变量保持含义。
3. 在现有格式化能力为 No 的数据源中核对无按钮；数据源切换或恢复 tab 后不得沿用上一个 tab 的能力。

预期：没有按 HANA 类型硬编码的按钮，也没有 MySQL/Oracle 可见但点击无动作的入口。未支持的语法显示统一提示，编辑器原文保留。

### HANA-UI-04 对象菜单与脚本

1. 在对象树中分别打开表、视图、过程、函数、触发器、序列、同义词的菜单。
2. 表使用“获取 DDL”入口；其他对象使用对应的获取脚本入口。检查脚本弹窗与所选对象一致。
3. 函数、同义词应能获取脚本；过程/函数不显示创建、修改、编译入口，触发器不显示修改、编译入口。
4. 上述对象不显示没有实现的“属性”入口；原生脚本的操作可通过 SQL 编辑器完成。
5. 核对复制、刷新、权限入口；在隔离对象上预览函数/过程删除 SQL，未经本流程需要不执行删除。

预期：可见菜单均有对应实现，获取脚本不修改数据库；取不到原生定义时按实际错误反馈，不伪造定义。详细结构回放复用 [HANA 结构编辑](../sql/hana_structure_editor.md)。

### HANA-UI-05 国际化和受限操作

1. 中文、英文各执行一次错误 SQL 结构诊断，核对“意外输入、缺少 token、语句结束、标识符”等提示。
2. 在结构/数据编辑中触发已定义的受限操作，核对只读列、缺少行键、生成列、精度范围和 DDL 转换限制使用对应语言，并保留列名、类型、行数参数。
3. 按 [HANA 数据编辑](../sql/hana_data_editor.md)、[权限验证](../security/hana_query_authorization.md)、[血缘与脱敏](../security/hana_lineage_masking.md) 执行已有流程；工单展示复用 [工单详情](../ticket/ticket_detail.md)。
4. 在 1440×900、1024×768、390×844 下查看中英文工具栏、配置说明和错误反馈，核对没有文字遮挡或按钮重叠。

预期：产品自身提示来自国际化资源；数据库原始错误允许保留厂商语言。长文案可正常展示，未支持项不静默返回空页面。

## Cleanup

- 恢复编辑器原文、语言与窗口尺寸；关闭仅为测试创建的 tab。
- 仅清理本流程创建的隔离对象，不删除已有实例或共享业务对象。

## Skip Conditions

- 服务不可达或未登录：页面流程标记 BLOCKED，不把离线验证记作页面通过。
- 缺少 HANA 实例/角色：连接、对象菜单实际调用、权限和数据库效果保留 NOT RUN；如已有可用工作台，可独立复测纯前端格式化。
- 缺少 MySQL/Oracle 对照连接：对应页面回归保持 NOT RUN，离线格式化样本不能替代 tab 能力与撤销验证。
- 缺少受限样本或窄屏模拟能力：明确记录未覆盖项，不伪造截图或运行结果。
