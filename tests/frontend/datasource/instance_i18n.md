# 实例页面国际化

## Purpose

验证实例列表的环境名称及列顺序，并确认列表和数据源新增、编辑表单跟随当前页面语言显示，防止环境与实例不匹配、列表操作文案大小写错误，以及后端动态表单面板、字段、说明和选项回退为中文。

## Scope

- 页面与路由：实例列表 `/#/datasource`、新增 `/#/datasource/add?dsType=<类型>`、编辑 `/#/datasource/add?mode=edit&dsId=<ID>&dsType=<类型>`。
- 关联接口：`POST /api/entry/datasource/listByCondition` 的 `dsEnvName`、`POST /api/entry/datasource/fetchDsConfig`，请求头 `Accept-Language`。
- 关联状态：浏览器语言设置、数据源类型、动态面板和字段配置。
- 不覆盖：连接测试结果、数据源提交、驱动下载、删除实例。

## Preconditions

- 本地服务可通过 `http://localhost:8222` 访问，并已加载包含本次改动的前后端构建产物。
- @Browser 已登录拥有实例查看、新增和编辑权限的测试账号。
- 实例列表至少存在一条 `CREATED` 状态的数据源，目标数据源插件包含 General、Options、SSH/SSL、Advanced 中至少两个非空面板。
- 测试期间不提交表单，不修改现有实例。

## Suites

### I18N-SMOKE-01 英文实例列表

- 风险/目的：P0，防止实例列表残留中文或操作按钮大小写错误。
- 初始路由与状态：`/#/datasource`，页面语言为中文，列表已加载 D02。
- @Browser 操作：通过页面语言菜单切换到 English，等待页面重新加载。
- 预期结果：标题为 `Instances`，列名依次为 `DataSource`、`Environment`、`Host`、`Operation`；操作按钮为 `Test`、`Modify`、`Delete`，`Test` 首字母大写。
- 恢复/清理：保持英文以继续后续场景。

### INSTANCE-ENV-01 环境名称与列表恢复

- 风险/目的：P0，确认实例展示保存的环境归属，避免环境名称与实例错位。
- 初始路由与状态：`/#/datasource`，使用 D05，列表加载完成。
- @Browser 操作：逐行比对环境页及实例编辑页中的已保存环境；不提交编辑表单。使用现有搜索定位实例，清除搜索，存在多页时切换页码，再刷新整页并离开、重新进入列表。通过语言菜单分别检查中英文。
- 预期结果：环境列位于数据源和网络地址之间；每行环境名称与已保存配置一致，刷新、搜索及分页后仍匹配当前实例；中文列名为“环境”，英文为 `Environment`；网络地址和原操作入口保留。直接展示接口的 `dsEnvName`，不按环境 ID 另行请求或在前端猜测环境名称。
- 恢复/清理：恢复原语言和搜索条件，不更改共享实例环境。

### INSTANCE-ENV-02 长名称与窄屏

- 风险/目的：P1，确认长环境名不挤压网络地址与操作列。
- 初始路由与状态：D06 已加载，分别使用 1440×900、1024×768、390×844 视口。
- @Browser 操作：检查长名称；桌面悬停被截断的环境名称，移动端按实际可用空间折叠侧栏并横向浏览表格。
- 预期结果：环境名称过长时省略展示，桌面提示可查看完整名称；列内容没有相互覆盖，窄屏可通过横向浏览到达环境及操作列。没有环境名称的历史记录保持空单元格，不伪造“生产”“默认”等归属。
- 恢复/清理：恢复原视口和侧栏状态，按 D05/D06 清理临时数据。

### I18N-MAIN-01 英文新增表单

- 风险/目的：P0，确认新增入口的动态配置使用当前请求语言。
- 初始路由与状态：英文实例列表，使用 D01。
- @Browser 操作：点击 `New`，选择 `MySQL` 并确认；依次打开 `General`、`Options`、`SSH/SSL`、`Advanced`。
- 预期结果：四个面板标题为英文或语言无关的 `SSH/SSL`；可见字段标签、说明、校验文案和选项不含中文；不点击 `Add DataSource`。
- 恢复/清理：返回实例列表。

### I18N-MAIN-02 英文编辑表单

- 风险/目的：P0，确认已有实例配置不会沿用中文默认 locale。
- 初始路由与状态：英文实例列表，D02 可见。
- @Browser 操作：点击 D02 行的 `Modify`；依次打开全部可见配置面板。
- 预期结果：面板标题、字段标签、说明和选项不含中文；已保存的非敏感配置值正常回填；页面底部按钮为 `Test Connection` 和 `Submit`。
- 恢复/清理：不修改、不保存，返回列表。

### I18N-BOUNDARY-01 Oracle 专有英文文案

- 风险/目的：P1，覆盖插件自身英文资源中的历史中文遗漏。
- 初始路由与状态：英文实例列表，使用 D03。
- @Browser 操作：点击 `New` 并选择 `Oracle`，查看包含 PDB 与 Oracle-maintained schemas 的配置区域。
- 预期结果：PDB 说明为英文；过滤 Oracle 系统 Schema 的标签和说明为英文；页面无中文配置文案。
- 恢复/清理：不提交表单，返回列表。

### I18N-EXTREME-01 面板逐项展开检查

- 风险/目的：P1，避免只检查默认面板而遗漏条件字段或较长说明。
- 初始路由与状态：英文新增或编辑页，选择具有最多可见配置项的数据源类型。
- @Browser 操作：遍历所有面板、下拉选项和会显示子字段的开关；使用窄窗口检查长英文说明。
- 预期结果：展开后的子字段和选项无中文；长文案可换行或完整展示，不遮挡输入框和底部操作区。
- 恢复/清理：恢复正常窗口宽度并离开页面。

### I18N-REPEAT-01 重复切换语言

- 风险/目的：P1，防止快速切换后旧响应覆盖当前语言。
- 初始路由与状态：实例列表可正常加载。
- @Browser 操作：切换为中文并等待重载，再切换为英文；进入新增页后返回列表，再次进入同一数据源类型。
- 预期结果：最终列表和两次新增页都以英文显示；没有混合语言或上一次中文响应残留。
- 恢复/清理：保持英文并返回列表。

### I18N-FAILURE-01 动态配置请求失败与恢复

- 风险/目的：P1，确认失败重试不会改变当前语言状态。
- 初始路由与状态：隔离环境可将 `fetchDsConfig` 临时返回 500 或模拟断网。
- @Browser 操作：英文模式进入新增页触发失败，恢复接口或网络后重新进入。
- 预期结果：失败由统一错误机制提示；恢复后重新请求携带英文 `Accept-Language`，表单以英文显示。
- 恢复/清理：恢复接口和网络配置。

### I18N-LIFECYCLE-01 刷新和前进后退

- 风险/目的：P1，验证语言在完整页面生命周期内一致。
- 初始路由与状态：英文新增或编辑页已加载。
- @Browser 操作：刷新页面，返回列表，再使用浏览器前进进入表单。
- 预期结果：路由与表单可恢复，列表及动态配置始终为英文，不出现中文闪回。
- 恢复/清理：返回列表。

### I18N-PERMISSION-01 无管理权限

- 风险/目的：P0，确认国际化改动不影响既有权限边界。
- 初始路由与状态：使用 D04，页面语言为英文。
- @Browser 操作：访问实例列表并尝试进入新增或编辑路由。
- 预期结果：列表按英文显示；`New`、`Modify`、`Delete` 不可见或路由被拒绝，不能进入可提交表单。
- 恢复/清理：恢复原账号或权限。

### I18N-STATE-01 请求语言与响应一致

- 风险/目的：P0，确认前后端语言契约一致。
- 初始路由与状态：英文新增页即将加载。
- @Browser 操作：在开发者工具 Network 中读取 `fetchDsConfig` 的非敏感请求头和响应显示文案。
- 预期结果：请求头 `Accept-Language` 为 `en-US`；响应中的面板、字段、说明和选项均为英文；刷新后的结果保持一致。
- 恢复/清理：关闭开发者工具，不提交表单。

## Cleanup

1. 关闭所有未提交的新增、编辑页面。
2. 恢复失败模拟、网络配置和测试账号权限。
3. 确认没有新增或修改任何数据源，关闭本流程创建的 @Browser 复测标签页。

## Skip Conditions

- 本地服务未加载本次前后端构建产物时，动态表单场景标记 SKIP；后端模块编译与资源扫描只能作为替代验证，不能代替最终页面复测。
- @Browser 未登录或缺少实例管理权限时，新增、编辑场景标记 SKIP，并保留权限覆盖缺口。
- 隔离环境无法安全模拟 500 或断网时，I18N-FAILURE-01 标记 SKIP，以接口契约和错误处理代码检查作为替代验证。
- 目标插件不提供某个空面板时，不强行显示该面板；只检查真实可见面板，并记录数据源类型与缺失面板。
