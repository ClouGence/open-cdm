## 第 1 步实库样本

样本标识为 `cdm_iot_231ab691`。两个实例分别创建维护账号 `cdm_iot_231ab691_maint` 和低权限账号 `cdm_iot_231ab691_read`。数据库和账号保留供后续步骤复用，密码单独保存。

| 编号 | 样本 | JDBC 直连证据 |
| --- | --- | --- |
| V1 | `root.cdm_iot_231ab691` | 维护账号列出两个设备、四个测点，读到对齐设备的两个温度值，并在测试测点完成建、写、读、清理。低权限账号仅列出和读到授权测点，查同设备的 `pressure` 返回空结果，写入被拒绝。 |
| V2T | `root.cdm_iot_231ab691` | 维护账号回读树库、两个设备、普通与对齐标志及四个测点，完成测试测点的建、写、读、清理。低权限账号仅列出和读到授权测点，查同设备的 `pressure` 返回空结果，写入被拒绝。 |
| V2R | `cdm_iot_231ab691` | 回读会话模式为 `TABLE`。维护账号列出两个表，`DESCRIBE` 返回四种列角色，采样表读到两台设备，并完成测试表的建、写、读、清理。低权限账号仅列出并能读取 `motor_samples`，查询 `motor_private` 和尝试写入均被明确拒绝。 |

## 第 2 步插件注册验证

| 能力 | 结果与证据 |
| --- | --- |
| 模块编译及插件包 | PASS。两个模块构建、`ds-iotdb:customFatJar`、Console 和 Sidecar 编译通过。包内包含 `sql-iotdb`、驱动工厂服务声明及驱动定义。JDBC 和平台共享 SDK 由各自加载层提供。 |
| 插件发现、配置和引擎 | PASS。独立 JVM 使用平台加载器发现隐藏的数据源插件和 `IoTDB SQL` 引擎。通过已注册的 provider 验证配置往返、非法 JSON 诊断及驱动属性。拆句和行为分析在方言实现前明确拒绝执行。 |
| 驱动下载、目录恢复与工厂 | PASS。平台 Maven 下载器从本地 HTTP 镜像准备两个版本的官方带依赖包。两个版本分别在新 JVM 使用 `files.idx` 恢复驱动，在 Maven 地址不可达的情况下通过工厂创建 JDBC 连接。低权限账号分别回读远端树模型样本的两条记录，连接关闭后状态为已关闭。另在同一 JVM 验证两个版本的绑定加载器各自独立。 |
| 公共加载器和驱动测试 | PASS。插件加载器现有测试通过。驱动模块现有 26 项测试重跑通过，其中删除资源后的毫秒时间戳断言在首次运行失败。 |

本步的工厂直连证据覆盖 V1 和 V2T 的 Tree 会话。Table 会话工厂、产品元数据和方言执行在后续步骤验证。
