# 3.3.0-rc.2

Release candidate for 3.3.0, following 3.3.0-rc.1.

## Highlights

- Datasource: cascade delete of child grants when a datasource is removed; add/edit forms gain stricter validation; datasource list layout and confirmation button behavior aligned.
- Driver loading: fix driver download for console/sidecar and switch driver download to runtime.
- Oracle: fix SSL/TCPS handshake path, including test fixtures for TCPS-enabled Oracle.
- Auth: preserve role auth filter expansion state on the role editor page.
- Classloader: fix `CgClassLoader` behavior for plugin/driver isolation.
- Backend housekeeping: relocate `AbstractDsConfigSpi` package and general code formatting.
- Build: keep arm64/x86_64 base images in sync; multi-arch buildx pipeline retained from rc.1.
