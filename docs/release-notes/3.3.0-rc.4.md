# 3.3.0-rc.4

Release candidate for 3.3.0, following 3.3.0-rc.3.

## Highlights

- Driver loading: refresh the matched driver version before creating a driver binding, so newly available or updated driver metadata is used when binding a datasource driver.
- Release assets: GitHub Releases now include generated Docker Compose and Kubernetes yml files for standalone and cluster deployments, in addition to the console, sidecar and alone tgz packages.
- Deployment templates: Docker Compose and Kubernetes templates now use explicit image prefix and image tag placeholders, keeping local packaging, channel yml generation and CD release assets aligned.
