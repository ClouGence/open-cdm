## Added

- Added personal SQL favorites with full-script saving, name search, opening, overwrite, save-as, rename, and delete operations; favorites are accessible across devices with the same account, with concurrent-edit conflict detection and confirmation before closing tabs with unsaved changes ([PR #365](https://github.com/ClouGence/open-cdm/pull/365)).
- Added support for Greenplum-specific SQL syntax, covering statement splitting, behavior analysis, and permission analysis for external tables, protocols, resource queues, and resource groups ([PR #362](https://github.com/ClouGence/open-cdm/pull/362)).
- Added support for Cloudberry-specific SQL syntax, covering statement splitting, behavior analysis, and permission analysis for external tables, protocols, resource management, and role extensions ([PR #356](https://github.com/ClouGence/open-cdm/pull/356)).
- Added Oracle administrative SQL support using 19c as the baseline, covering parsing, classification, and behavior analysis for session, system, role, audit policy, tablespace, and database management statements ([PR #338](https://github.com/ClouGence/open-cdm/pull/338)).
- Added SQL Server administrative SQL support using 2022 as the baseline, with statement parsing, splitting, and behavior analysis ([PR #345](https://github.com/ClouGence/open-cdm/pull/345)).
- Added StarRocks administrative SQL support using 3.5.21 as the baseline, covering parsing and behavior analysis for administrative operations, jobs, and execution plans ([PR #348](https://github.com/ClouGence/open-cdm/pull/348)).
- Added ClickHouse administrative SQL support using 26.8 LTS as the baseline, covering parsing and behavior analysis for access control, system management, maintenance, and execution plans ([PR #354](https://github.com/ClouGence/open-cdm/pull/354)).
- Added OceanBase for MySQL administrative SQL support using 4.2.5 LTS as the baseline, covering parsing and behavior analysis for sessions, users and roles, system management, maintenance, and execution plans ([PR #366](https://github.com/ClouGence/open-cdm/pull/366)).
- Added support and completion for read-only MongoDB `rs.*` and `sh.*` shell helpers to query replica-set configuration, replication status, shards, and balancer status, contributed by community contributor [@48N6E](https://github.com/48N6E)—thank you! ([PR #333](https://github.com/ClouGence/open-cdm/pull/333)).

## Fixed

- Fixed statement splitting, classification, and behavior analysis for affected MySQL, MariaDB, PostgreSQL, Doris, TiDB, and Dameng SQL syntax; expanded built-in function and system object recognition, and corrected statement type checks during query row-limit rewriting ([PR #337](https://github.com/ClouGence/open-cdm/pull/337)).
- Fixed the SQL workspace closing sessions after queries in auto-commit mode and losing session settings; parsing now uses the current session's `SQL_MODE`, with improved transaction statement execution and state synchronization in manual-commit mode ([PR #337](https://github.com/ClouGence/open-cdm/pull/337)).
- Fixed PostgreSQL `vector` and `halfvec` column types not being recognized when qualified with a schema name, contributed by community contributor [@sunjiajie](https://github.com/sunjiajie)—thank you! ([PR #280](https://github.com/ClouGence/open-cdm/pull/280)).
- Fixed approval scheduling repeatedly updating idle tickets' modification timestamps and amplifying database writes and binlogs; active and idle tickets are scanned separately, with fewer SQL payload reads during idle checks ([PR #339](https://github.com/ClouGence/open-cdm/pull/339)).
- Fixed the approval workflow template dropdown in environment-level SQL ticket settings preventing users from browsing all templates when more than six were available, contributed by community contributor [@fengruiwd](https://github.com/fengruiwd)—thank you! ([PR #340](https://github.com/ClouGence/open-cdm/pull/340)).
- Fixed form bindings for datasource remarks, ticket titles and descriptions, and the data generator's continue-on-error option in the SQL workspace so that entered and checked values update correctly, contributed by community contributor [@fengruiwd](https://github.com/fengruiwd)—thank you! ([PR #347](https://github.com/ClouGence/open-cdm/pull/347)).
- Fixed unclear datasource connection error messages in the SQL workspace by displaying the failed datasource's name and icon and simplifying dialog actions ([PR #365](https://github.com/ClouGence/open-cdm/pull/365)).
