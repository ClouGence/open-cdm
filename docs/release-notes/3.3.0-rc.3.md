# 3.3.0-rc.3

Release candidate for 3.3.0, following 3.3.0-rc.2.

## Highlights

- Built-in drivers: Docker images now bundle MySQL Connector/J 8.4.0, PostgreSQL JDBC 42.7.10 and Jedis 7.4.1, so common datasources work out of the box without downloading drivers.
- Driver loading: driver versions missing from the writable driver directory now fall back to a read-only built-in directory (`${app.home}/built-in-drivers`, overridable via `-DbuiltinDriverDirectory`); downloads and deletes keep targeting the writable directory, and a downloaded copy always wins over the bundled one.
- Build: the built-in driver bundle is resolved at build time from `package/docker/built-in-drivers.xml` by the new `pkg-builtin-drivers` module and baked into the alone/console/sidecar image layers; tgz packages stay unchanged.
